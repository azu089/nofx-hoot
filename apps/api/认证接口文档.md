# QuantFi 认证接口文档

## 概述

JWT 认证模块已实现，包含用户注册和登录功能。

## 接口列表

### 1. 用户注册

**接口地址**: `POST /api/auth/register`

**请求参数**:
```json
{
  "email": "user@example.com",
  "password": "password123",
  "inviteCode": "AGENT001" // 可选，代理商邀请码
}
```

**参数说明**:
- `email`: 邮箱地址，必须符合邮箱格式
- `password`: 密码，8-32位
- `inviteCode`: 代理商邀请码（可选）

**成功响应** (201):
```json
{
  "code": 0,
  "message": "注册成功",
  "data": {
    "id": "uuid",
    "email": "user@example.com",
    "vipLevel": 0,
    "agentId": null,
    "inviteCode": null,
    "status": "active",
    "createdAt": "2025-12-24T01:16:11.865Z",
    "updatedAt": "2025-12-24T01:16:11.865Z"
  },
  "request_id": "uuid"
}
```

**错误响应**:
- 40000: 参数错误（邮箱格式不正确、密码长度不符等）
- 40001: 邀请码无效
- 40002: 该代理商已被禁用
- 50000: 邮箱已被注册

**业务逻辑**:
1. 验证邮箱格式和密码长度
2. 检查邮箱是否已存在
3. 验证邀请码（如提供）
4. bcrypt 加密密码（10轮盐值）
5. **事务操作**：
   - 创建用户记录
   - 自动创建钱包（余额为0）
   - 更新代理商用户数（如有邀请码）
6. 返回用户信息（不含密码）

---

### 2. 用户登录

**接口地址**: `POST /api/auth/login`

**请求参数**:
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**参数说明**:
- `email`: 邮箱地址
- `password`: 密码

**成功响应** (200):
```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": "uuid",
      "email": "user@example.com",
      "vipLevel": 0,
      "agentId": null,
      "inviteCode": null,
      "status": "active",
      "createdAt": "2025-12-24T01:16:11.865Z",
      "updatedAt": "2025-12-24T01:16:11.865Z"
    }
  },
  "request_id": "uuid"
}
```

**错误响应**:
- 40000: 参数错误
- 41000: 邮箱或密码错误
- 41001: 账号已被禁用，请联系客服

**业务逻辑**:
1. 验证邮箱和密码
2. 检查用户状态（是否被禁用）
3. 生成 JWT Token（有效期7天）
4. 更新最后登录时间和IP
5. 返回 Token 和用户信息

**JWT Token 说明**:
- 算法: HS256
- 有效期: 7天（默认）
- Payload 包含:
  - `sub`: 用户 ID
  - `email`: 邮箱
  - `vipLevel`: VIP 等级

## 使用示例

### 1. 注册新用户

```bash
curl -X POST http://localhost:4001/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@quantfi.com",
    "password": "password123"
  }'
```

### 2. 用户登录

```bash
curl -X POST http://localhost:4001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@quantfi.com",
    "password": "password123"
  }'
```

### 3. 使用 Token 访问受保护的接口

```bash
curl -X GET http://localhost:4001/api/users/profile \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

## 安全特性

### 1. 密码安全
- 使用 bcrypt 加密存储
- 盐值轮次: 10
- 密码长度: 8-32位

### 2. JWT 安全
- 使用环境变量配置密钥
- 生产环境必须使用强密钥（≥32位）
- Token 过期时间: 7天（可配置）

### 3. 日志脱敏
- 仅记录用户 ID 和邮箱
- 不记录密码、Token 等敏感信息
- 每次请求包含 request_id

### 4. 错误处理
- 邮箱或密码错误时返回统一错误信息（防止用户枚举）
- 参数校验失败返回具体错误原因
- 所有错误包含 request_id 便于定位

## 环境变量配置

需要在 `.env` 文件中配置：

```bash
# JWT 配置
JWT_SECRET=your-jwt-secret-key-change-in-production
JWT_EXPIRES_IN=7d
JWT_REFRESH_EXPIRES_IN=30d
```

**注意**: 生产环境必须更换 JWT_SECRET，建议使用至少32位的随机字符串。

## 常见问题

### Q: 为什么注册时自动创建钱包？
A: 为了保证数据一致性，注册和创建钱包在同一个事务中完成。如果钱包创建失败，整个注册操作会回滚。

### Q: Token 过期后如何处理？
A: 当前版本 Token 过期后需要重新登录。后续会实现 refresh token 机制，无需重新输入密码即可续期。

### Q: 如何修改 JWT 有效期？
A: 在 `.env` 文件中修改 `JWT_EXPIRES_IN` 配置，例如 `JWT_EXPIRES_IN=30d` 表示30天。

### Q: 忘记密码怎么办？
A: 当前版本暂未实现找回密码功能，后续会添加邮箱重置密码功能。
