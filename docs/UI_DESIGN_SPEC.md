# QuantFi UI 设计规范 - Robinhood 简约风格

> 版本: v1.0
> 更新日期: 2026-01-11
> 设计方向: **Robinhood 简约风格 + 当前布局优化**
> 状态: 设计方案待确认

---

## 一、设计方向定义

### 1.1 核心理念：Less is More

基于 [Robinhood UX/UI 设计理念](https://www.linkedin.com/pulse/how-robinhoods-uxui-design-shaping-future-investing-johnson-jr--srljc)，我们采用以下设计原则：

| 原则 | Robinhood 做法 | QuantFi 应用 |
|------|---------------|-------------|
| **极简信息** | 一次只展示一个决策点 | 每个卡片只展示核心指标 |
| **颜色即信息** | 绿涨红跌，无需文字说明 | 盈亏用颜色区分，减少标签 |
| **大字体数字** | 核心数据用超大字体 | 总资产、盈亏用 32-48px |
| **卡片式布局** | 每个数据块是独立卡片 | 保持当前卡片结构，优化间距 |
| **渐进式披露** | 复杂信息可折叠/展开 | 详情用 Sheet/Modal 展开 |

### 1.2 与当前 UI 的关系

**保持不变的部分**：
- 整体布局结构 (Sidebar + Main)
- 页面路由和导航
- 功能模块划分
- 暗色主题基调

**需要优化的部分**：
- 配色方案微调
- 数字字体和大小
- 卡片间距和圆角
- 减少视觉噪音
- 增强核心数据的视觉权重

## 二、配色方案优化

### 2.1 当前配色 vs 优化后配色

| 用途 | 当前色值 | 优化后色值 | 变化说明 |
|------|---------|-----------|---------|
| 主背景 | #0B0E11 | **#000000** | 更纯净的黑色 (Robinhood 风格) |
| 卡片背景 | #131722 | **#0D0D0D** | 稍微提亮，增加层次感 |
| 输入框背景 | #1E222D | **#1A1A1A** | 中性灰，减少蓝调 |
| 品牌主色 | #3772FF | **#00D632** | Robinhood 标志性绿色 |
| 盈利色 | #00C087 | **#00D632** | 更鲜艳的绿色 |
| 亏损色 | #F23645 | **#FF5252** | 更柔和的红色 |
| 主文字 | #FFFFFF | #FFFFFF | 保持不变 |
| 次要文字 | #848E9C | **#8C8C8C** | 中性灰 |
| 辅助文字 | #5E6673 | **#666666** | 中性灰 |

### 2.2 优化后完整配色表

```css
:root {
  /* ===== 背景层次 (Robinhood 纯黑风格) ===== */
  --bg-primary: #000000;         /* 主背景 - 纯黑 */
  --bg-secondary: #0D0D0D;       /* 卡片背景 - 近黑 */
  --bg-tertiary: #1A1A1A;        /* 输入框/悬浮 - 深灰 */
  --bg-hover: #262626;           /* 悬浮态 */

  /* ===== 品牌色 (Robinhood 绿) ===== */
  --brand-primary: #00D632;      /* Robinhood 标志绿 */
  --brand-secondary: #00B828;    /* 深绿悬浮态 */

  /* ===== 语义色 ===== */
  --success: #00D632;            /* 盈利/涨 - 与品牌色统一 */
  --danger: #FF5252;             /* 亏损/跌 */
  --warning: #FFB300;            /* 警告/待处理 */
  --info: #2196F3;               /* 信息/链接 */

  /* ===== 文字 ===== */
  --text-primary: #FFFFFF;       /* 主文字 */
  --text-secondary: #8C8C8C;     /* 次要文字 */
  --text-tertiary: #666666;      /* 辅助文字 */

  /* ===== 边框 ===== */
  --border-primary: #262626;     /* 主边框 */
  --border-secondary: #1A1A1A;   /* 次级边框 */
}
```

## 三、字体规范优化

### 3.1 Robinhood 字体特点

- **数字使用等宽字体** - 确保价格对齐
- **核心数据超大字体** - 48px 以上
- **辅助信息小而轻** - 12-14px，低对比度

### 3.2 优化后字体规范

```css
/* 主字体保持不变 */
font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;

/* 数字专用 - 等宽 */
.font-mono {
  font-family: 'SF Mono', 'JetBrains Mono', 'Roboto Mono', monospace;
  font-variant-numeric: tabular-nums;
}

/* 字号层级优化 */
--text-xs: 11px;     /* 时间戳、辅助标签 */
--text-sm: 13px;     /* 次要信息 */
--text-base: 15px;   /* 正文 */
--text-lg: 17px;     /* 小标题 */
--text-xl: 20px;     /* 卡片标题 */
--text-2xl: 28px;    /* 重要数据 */
--text-3xl: 36px;    /* 核心指标 */
--text-4xl: 48px;    /* 英雄数字 (总资产) */
```

### 3.3 数字展示规范

| 数据类型 | 字体大小 | 字重 | 示例 |
|---------|---------|------|------|
| 总资产 | 48px | Bold | **$9,127.50** |
| 今日盈亏 | 28px | Semibold | +$125.80 |
| 持仓盈亏 | 20px | Medium | +2.35% |
| 价格 | 15px | Regular | 67,800.50 |
| 标签 | 11px | Regular | 做多 · 3x |

## 四、间距与布局优化

### 4.1 Robinhood 间距特点

- **大留白** - 内容之间有呼吸空间
- **统一间距** - 使用 8px 基数倍数
- **卡片内边距充足** - 通常 20-24px

### 4.2 优化后间距规范

```css
/* 间距系统 (8px 基数) */
--space-1: 4px;      /* 最小间距 */
--space-2: 8px;      /* 紧凑间距 */
--space-3: 12px;     /* 标准小间距 */
--space-4: 16px;     /* 标准间距 */
--space-5: 20px;     /* 卡片内边距 */
--space-6: 24px;     /* 区块间距 */
--space-8: 32px;     /* 大区块间距 */
--space-10: 40px;    /* 页面顶部间距 */

/* 卡片间距优化 */
.card {
  padding: 20px;           /* 内边距增加 */
  margin-bottom: 16px;     /* 卡片间距 */
  border-radius: 12px;     /* 圆角统一 */
}

/* 页面内容区 */
.page-content {
  padding: 24px;           /* 页面内边距 */
  max-width: 1200px;       /* 最大宽度 */
  gap: 16px;               /* 网格间距 */
}
```

### 4.3 圆角规范

| 元素 | 当前圆角 | 优化后圆角 |
|------|---------|-----------|
| 按钮 | 6px | **8px** |
| 输入框 | 6px | **8px** |
| 卡片 | 8-12px | **12px** (统一) |
| 弹窗 | 12px | **16px** |
| 标签/徽章 | 4px | **6px** |

## 五、核心组件设计规范

### 5.1 资产卡片 (AssetHeroCard)

**当前状态**:
```
┌────────────────────────────────────┐
│ 总资产 (USDT)              [刷新]  │
│ 9127.50 USDT                      │
│ 今日盈亏: +0.00% | 点卡 | 代币    │
└────────────────────────────────────┘
```

**优化后设计** (Robinhood 风格):
```
┌────────────────────────────────────┐
│                                    │
│  Total Balance                     │  ← 11px 灰色标签
│                                    │
│  $9,127.50                         │  ← 48px 白色粗体
│                                    │
│  +$0.00 (0.00%) today              │  ← 20px 绿色
│                                    │
│  ───────────────────────────────   │  ← 分隔线
│                                    │
│  Points      Tokens                │
│  24,520      1,397                 │  ← 24px 数字
│                                    │
└────────────────────────────────────┘
```

**设计要点**:
- 移除"USDT"单位，使用 "$" 符号
- 总资产字体放大到 48px
- 盈亏金额和百分比同行显示
- 底部双列显示积分/代币
- 整体增加垂直留白

## 六、页面布局优化

### 6.1 Dashboard 页面

**当前布局**:
```
[资产卡片]
[公告滚动条]
[快捷入口 6个]
[恐惧贪婪指数]
[新手任务]
[热门资讯]
```

**优化后布局** (减少模块，增加留白):
```
[资产卡片 - 放大，更多留白]

[快捷入口 - 精简为 4 个核心入口]
 ┌────┐ ┌────┐ ┌────┐ ┌────┐
 │交易│ │策略│ │充值│ │邀请│
 └────┘ └────┘ └────┘ └────┘

[市场情绪 - 简化显示]

[新手任务 - 折叠式，默认收起]
```

**变化说明**:
- 移除公告滚动条 (或改为可关闭)
- 快捷入口从 6 个减少到 4 个
- 恐惧贪婪指数简化为单行
- 新手任务默认折叠
- 热门资讯移到单独页面

### 6.2 Trading 页面

**当前布局**:
```
[类型切换 + 时间范围]
[盈亏概览 3 列]
[收益曲线]
[Tab: 持仓/历史/日志]
[持仓列表]
```

**优化后布局**:
```
[总盈亏 - 大字体居中显示]
  +$0.00
  Total P&L

[盈亏细分 - 小字灰色]
  Today +$0.00 · This Month +$0.00

[Tab: 持仓/历史/日志]

**变化说明**:
- 移除类型切换到顶部菜单
- 盈亏显示更聚焦，突出总盈亏
- 收益曲线可折叠或移除
- 增加持仓卡片间距

### 6.3 Strategies 页面

**当前布局**:
```
[标题 + 按钮]
[筛选栏 5 个下拉]
[策略卡片 3 列网格]
```

**优化后布局**:
```
[标题]
Strategies

[筛选标签 - 横向滚动]

**变化说明**:
- 筛选从下拉改为标签按钮
- 卡片从 3 列改为 2 列 (更大卡片)
- 增加搜索框视觉权重

## 七、交互优化

### 7.1 反馈机制

| 交互 | 当前效果 | 优化后效果 |
|------|---------|-----------|
| 按钮点击 | 颜色变化 | 颜色变化 + 轻微缩放 (0.98) |
| 卡片悬浮 | 边框高亮 | 背景微亮 + 轻微上移 (2px) |
| 加载状态 | Spinner | Skeleton 骨架屏 |
| 成功反馈 | Toast | Toast + 绿色闪烁 |
| 数据刷新 | 无动画 | 数字滚动动画 |

### 7.2 过渡动画

```css
/* 统一过渡时长 */
--transition-fast: 100ms ease-out;
--transition-normal: 200ms ease-out;
--transition-slow: 300ms ease-out;

/* 按钮点击 */
.button:active {
  transform: scale(0.98);
  transition: transform var(--transition-fast);
}

/* 卡片悬浮 */
.card:hover {
  background: var(--bg-hover);
  transform: translateY(-2px);
  transition: all var(--transition-normal);
}
```
