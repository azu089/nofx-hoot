# 代币兑换与释放验算

## 兑换率验算

- 兑换率：1000 积分 = 1 $QFI
- 公式：`tokens = points / 1000`

### 示例
- 10000 积分 → 10 $QFI ✓
- 5000 积分 → 5 $QFI ✓
- 1000 积分 → 1 $QFI ✓

---

## 标准模式验算（20% 立即 + 80% 释放 90 天）

### 公式
```
总代币 = points / 1000
立即到账 = 总代币 × 20% = 总代币 × 0.2
待释放 = 总代币 × 80% = 总代币 × 0.8
每日释放 = 待释放 / 90
```

### 示例 1：10000 积分
```
总代币 = 10000 / 1000 = 10 QFI
立即到账 = 10 × 0.2 = 2 QFI
待释放 = 10 × 0.8 = 8 QFI
每日释放 = 8 / 90 = 0.08888888 QFI
```

### 验证
- Day 0: 立即获得 2 QFI ✓
- Day 1: 释放 0.08888888 QFI，已释放 2.08888888 QFI ✓
- Day 2: 释放 0.08888888 QFI，已释放 2.17777776 QFI ✓
- Day 90: 全部释放完毕，已释放 10 QFI ✓

---

## 急速模式验算（50% 立即 + 50% 销毁）

### 公式
```
总代币 = points / 1000
立即到账 = 总代币 × 50% = 总代币 × 0.5
销毁 = 总代币 × 50% = 总代币 × 0.5
待释放 = 0
```

### 示例 1：5000 积分
```
总代币 = 5000 / 1000 = 5 QFI
立即到账 = 5 × 0.5 = 2.5 QFI
销毁 = 5 × 0.5 = 2.5 QFI
待释放 = 0 QFI
```

### 验证
- 用户获得：2.5 QFI ✓
- 平台销毁：2.5 QFI（记录到 token_burns 表）✓
- 无待释放 ✓

---

## 钱包余额验算

### 标准模式（10000 积分兑换 10 QFI）
```
兑换前积分：10000
兑换后积分：0
兑换前代币：0
兑换后代币（可用）：2 QFI
兑换后代币（待释放）：8 QFI
兑换后代币（总计）：10 QFI
```

### 急速模式（5000 积分兑换 5 QFI）
```
兑换前积分：5000
兑换后积分：0
兑换前代币：2 QFI
兑换后代币（可用）：2 + 2.5 = 4.5 QFI
兑换后代币（待释放）：8 QFI（不变）
兑换后代币（总计）：12.5 QFI
```

## 数据库约束验算

### token_orders 表验算
```
points_spent: 10000.00000000 (DECIMAL 18,8)
tokens_total: 10.00000000 (DECIMAL 18,8)
exchange_rate: 1000.00000000 (DECIMAL 18,8)
tokens_released: 2.00000000 (DECIMAL 18,8)
tokens_pending: 8.00000000 (DECIMAL 18,8)
tokens_burned: 0.00000000 (DECIMAL 18,8)

验算：tokens_total = tokens_released + tokens_pending + tokens_burned
10 = 2 + 8 + 0 ✓
```

### wallets 表验算
```
标准模式兑换后：
token_balance: 2.00000000
token_vesting: 8.00000000
token_locked: 0.00000000

验算：token_total = token_balance + token_vesting + token_locked
10 = 2 + 8 + 0 ✓
```

## 释放进度验算（第 30 天）

### 示例：10000 积分标准模式
```
总待释放：8 QFI
每日释放：8 / 90 = 0.08888888 QFI
第 30 天已释放：0.08888888 × 30 = 2.66666640 QFI
第 30 天待释放：8 - 2.66666640 = 5.33333360 QFI
总已释放：2 (立即) + 2.66666640 (线性) = 4.66666640 QFI
释放进度：4.66666640 / 10 = 46.67% ✓
剩余天数：90 - 30 = 60 天 ✓
```

---

## 误差容忍

- 所有代币计算使用 **DECIMAL(18,8)**
- 精度：小数点后 8 位
- 容忍误差：**0**（必须精确匹配，使用 decimal.js 避免浮点数误差）

## 测试用例

### 正常路径
1. ✅ 标准模式兑换：20% 立即到账正确
2. ✅ 急速模式兑换：50% 销毁正确记录

### 异常路径
1. ✅ 积分余额不足：抛出 BadRequestException
2. ✅ 钱包不存在：抛出 NotFoundException
3. ✅ 最少兑换 1000 积分：DTO 校验失败

### 边界路径
1. ✅ 最后一天释放：剩余代币全部释放（避免精度损失）
2. ✅ 释放完成后：订单状态变更为 completed
