# 积分计算验算脚本

## 验算公式

### 基础积分计算
```
基础积分 = 交易量 (USDT) ÷ 100 × 1
```

### VIP 加成计算
```
实际获得积分 = 基础积分 × VIP倍数

VIP 倍数：
- VIP0 (普通用户): 1.0x
- VIP1: 1.2x
- VIP2: 1.5x
- VIP3: 2.0x
```

## 验算工具（Node.js）

```javascript
// 使用 decimal.js 进行精确计算
const Decimal = require('decimal.js');

function calculatePoints(tradeVolume, vipLevel) {
  // VIP 倍数映射
  const vipMultipliers = {
    0: new Decimal('1.0'),
    1: new Decimal('1.2'),
    2: new Decimal('1.5'),
    3: new Decimal('2.0'),
  };

  // 基础积分计算
  const volume = new Decimal(tradeVolume);
  const basePoints = volume.dividedBy('100').times('1');

  // 应用 VIP 加成
  const vipMultiplier = vipMultipliers[vipLevel] || vipMultipliers[0];
  const earnedPoints = basePoints.times(vipMultiplier).toDecimalPlaces(8);

  return earnedPoints.toString();
}

// 测试
console.log('案例 1:', calculatePoints('1000', 0));  // 预期: 10.00000000
console.log('案例 2:', calculatePoints('1000', 1));  // 预期: 12.00000000
console.log('案例 3:', calculatePoints('5000', 2));  // 预期: 75.00000000
console.log('案例 4:', calculatePoints('10000', 3)); // 预期: 200.00000000
console.log('案例 5:', calculatePoints('50', 0));    // 预期: 0.50000000
console.log('案例 6:', calculatePoints('0.01', 0));  // 预期: 0.00010000
```

## SQL 验算查询

### 查询用户积分获取记录
```sql
SELECT
  bl.user_id,
  u.vip_level,
  bl.amount AS earned_points,
  bl.description,
  bl.created_at
FROM billing_logs bl
JOIN users u ON u.id = bl.user_id
WHERE bl.billing_type = 'points_earn'
  AND bl.currency = 'POINTS'
ORDER BY bl.created_at DESC
LIMIT 10;
```

### 验证积分余额一致性
```sql
-- 计算用户积分总和（获得 - 扣除）
WITH points_summary AS (
  SELECT
    user_id,
    SUM(CASE WHEN billing_type = 'points_earn' THEN amount::DECIMAL ELSE 0 END) AS total_earned,
    SUM(CASE WHEN billing_type = 'points_deduct' THEN ABS(amount::DECIMAL) ELSE 0 END) AS total_deducted
  FROM billing_logs
  WHERE currency = 'POINTS'
    AND status = 'completed'
  GROUP BY user_id
)
SELECT
  ps.user_id,
  ps.total_earned,
  ps.total_deducted,
  ps.total_earned - ps.total_deducted AS expected_balance,
  w.points_balance AS actual_balance,
  (ps.total_earned - ps.total_deducted) - w.points_balance AS difference
FROM points_summary ps
JOIN wallets w ON w.user_id = ps.user_id
WHERE ABS((ps.total_earned - ps.total_deducted) - w.points_balance) > 0.00000001;
-- 如果有结果，说明存在不一致
```

## 容忍误差

**积分计算必须精确匹配，容忍误差为 0**

所有积分计算使用 DECIMAL(18,8) 类型，精确到 8 位小数。

## 幂等性验证

### 验证同一交易不会重复获取积分
```sql
SELECT
  reference_id AS trade_id,
  COUNT(*) AS count
FROM billing_logs
WHERE billing_type = 'points_earn'
  AND reference_type = 'trade_history'
GROUP BY reference_id
HAVING COUNT(*) > 1;
-- 如果有结果，说明同一交易获取了多次积分（违反幂等性）
```

### 验证唯一订单 ID
```sql
SELECT
  unique_order_id,
  COUNT(*) AS count
FROM billing_logs
WHERE billing_type IN ('points_earn', 'points_deduct')
GROUP BY unique_order_id
HAVING COUNT(*) > 1;
-- 如果有结果，说明存在重复的订单 ID（违反唯一性）
```
