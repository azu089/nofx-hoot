## 2. 执行摘要

### 2.1 Refresh Token 机制

#### 后端实现
- **新增文件**: `apps/api/src/modules/auth/dto/refresh-token.dto.ts`
- **修改文件**: `apps/api/src/modules/auth/auth.service.ts`
- **修改文件**: `apps/api/src/modules/auth/auth.controller.ts`
- **修改文件**: `apps/api/src/modules/auth/dto/auth-response.dto.ts`

**功能特性**:
- Access Token 有效期: 7 天
- Refresh Token 有效期: 30 天
- Token 轮换：每次刷新时颁发新的 Refresh Token
- 安全验证：使用 tokenHash 防止 Token 重放

#### 前端实现
- **修改文件**: `apps/web/src/lib/api.ts`
- **修改文件**: `apps/web/src/stores/auth.store.ts`

**功能特性**:
- 自动刷新：401 错误时自动尝试刷新 Token
- 请求队列：刷新期间其他请求等待，刷新成功后重试
- Token 存储：localStorage 存储 access_token 和 refresh_token
- 自动登出：刷新失败时清除 Token 并跳转登录页

### 2.2 积分抵扣订阅

- **修改文件**: `apps/web/src/app/(dashboard)/instances/page.tsx`
- **修改文件**: `apps/web/src/lib/api.ts` (instancesApi.create 添加 usePoints 参数)

**功能特性**:
- 创建 VPS 时显示创建对话框
- 显示积分余额（从 GameFi API 获取）
- 支持勾选"使用积分抵扣"
- 显示费用明细（订阅费用 - 积分抵扣 = 实际支付）
- 1 积分 = 1 USDT

### 2.3 2FA 验证

#### 提现时验证弹窗
- **修改文件**: `apps/web/src/app/(dashboard)/wallet/page.tsx`

**功能特性**:
- 检测用户是否启用 2FA
- 启用 2FA 时提现需要输入验证码
- 6 位数字验证码输入框
- 显示提现详情（金额、链、地址）

#### 安全设置页面开关
- **修改文件**: `apps/web/src/app/(dashboard)/settings/page.tsx`

**功能特性**:
- 显示 2FA 当前状态（已启用/未启用）
- 启用流程：获取二维码 → 扫描 → 输入验证码 → 确认
- 禁用流程：输入验证码 + 账户密码 → 确认
- 显示 TOTP 密钥供手动输入
- 密钥备份提示
