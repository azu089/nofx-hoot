## 3. 技术实现

### 统一模式

所有页面采用一致的技术模式：

1. **Client Component**: 使用 `'use client'` 指令
2. **UI 组件**: 从 `@repo/design-system` 导入 Card, Button, Input 等
3. **图标**: 使用 `lucide-react` 图标库
4. **样式**: TailwindCSS + 语义化类名
5. **数据**: Mock 数据模拟，预留 API 接口位置

### 页面功能亮点

| 页面 | 功能特点 |
|------|---------|
| 安全设置 | 密码修改、2FA 设置、登录历史 |
| 紧急按钮 | 四级紧急操作（停止策略/平仓/撤销API/销毁VPS） |
| 质押大厅 | A类（灵活）和B类（锁仓）质押 |
| 积分兑换 | 标准模式（100:1）和急速模式（110:1） |
| 回测系统 | 策略选择、时间范围、资金配置、结果展示 |
| AI 策略 | 对话式 AI 策略生成器 |
| 帮助中心 | 分类 FAQ、搜索功能、快速入口 |
| 策略详情 | 完整策略信息、订阅计划选择、用户评价 |
| 仪表盘 | 公告栏、快速操作、运行策略、资产分布、最近交易 |
