## 4. 验证方式

### 预览组件
1. 确保 shadcn/ui 已安装
2. 确保 Tailwind CSS 配置正确
3. 在页面中导入组件：

```tsx
// 桌面端
import { DashboardPage } from '@/components/ui-v3'

export default function Page() {
  return <DashboardPage />
}

// 移动端
import { MobileDashboard } from '@/components/ui-v3'

export default function MobilePage() {
  return <MobileDashboard />
}
```

### 启动开发服务器
```bash
cd apps/web
pnpm dev
```

访问 http://localhost:3001 查看效果

## 5. 依赖要求

组件依赖以下库：
- `@/components/ui/card` (shadcn/ui)
- `@/components/ui/button` (shadcn/ui)
- `@/components/ui/input` (shadcn/ui)
- `lucide-react` (图标)
- `clsx` + `tailwind-merge` (cn 工具函数)

如果缺失，需要安装：
```bash
npx shadcn@latest add card button input
pnpm add lucide-react clsx tailwind-merge
```

## 6. 回滚方案

删除 ui-v3 目录：
```bash
rm -rf apps/web/src/components/ui-v3
```
