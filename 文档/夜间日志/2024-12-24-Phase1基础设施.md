## 3. 技术决策记录

### 端口配置

| 服务 | 端口 | 原因 |
|------|------|------|
| PostgreSQL | 5433 | 5432 被 gamefi-postgres 占用 |
| API | 4001 | 4000 被其他项目占用 |
| Frontend | 3001 | 3000 被其他项目占用 |
| Redis | 6379 | 默认端口 |

### 关键技术选型

| 组件 | 选型 | 原因 |
|------|------|------|
| ORM | Prisma 7 + adapter-pg | 最新稳定版，PostgreSQL 适配 |
| 密码加密 | bcrypt (10 rounds) | 行业标准 |
| 金额计算 | decimal.js | 避免浮点数精度问题 |
| JWT | @nestjs/jwt + passport | NestJS 官方推荐 |

### 数据库设计

- 所有金额字段使用 `DECIMAL(18,8)`
- 所有表包含 `created_at`, `updated_at` 审计字段
- 使用 UUID 作为主键
- 外键约束确保数据完整性
