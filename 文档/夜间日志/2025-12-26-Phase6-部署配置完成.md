## 3. 功能详情

### 3.1 docker-compose.prod.yml

生产环境 Docker Compose 配置，包含：

- PostgreSQL 16 Alpine（内存限制 1G）
- Redis 7 Alpine（内存限制 512M）
- API 服务（内存限制 1G）
- Web 前端（内存限制 512M）
- Nginx 反向代理
- 内部网络（数据库隔离）
- 外部网络（API/Web 访问）

特性：
- 健康检查配置
- 资源限制
- 日志轮转
- 环境变量验证

### 3.2 Nginx 配置

- SSL/TLS 配置（TLS 1.2/1.3）
- Gzip 压缩
- 安全头（X-Frame-Options, X-Content-Type-Options）
- 限流配置（10 req/s）
- WebSocket 支持
- Let's Encrypt 集成准备

### 3.3 GitHub Actions CI/CD

**CI 流水线 (ci.yml)**：
- Lint & Type Check
- 单元测试 + 覆盖率上传
- E2E 测试（PostgreSQL + Redis 服务）
- 构建检查
- 安全扫描（pnpm audit + trufflehog）

**CD 流水线 (deploy.yml)**：
- 构建 Docker 镜像
- 推送到 GitHub Container Registry
- SSH 部署到服务器
- 数据库迁移
- 健康检查
- Slack 通知

### 3.4 监控脚本

`scripts/运维/监控检查.sh`：
- HTTP 服务检查（API、Web）
- Docker 容器状态
- 数据库连接检查
- Redis 连接检查
- 磁盘使用率告警（阈值 80%）
- 内存使用率告警（阈值 80%）
- Slack/邮件告警支持

### 3.5 备份脚本

`scripts/运维/数据库备份.sh`：
- PostgreSQL 全库备份
- Gzip 压缩
- S3 上传（可选）
- 自动清理旧备份（默认保留 7 天）
- Docker 容器内执行支持

`scripts/运维/数据库恢复.sh`：
- 支持压缩/未压缩备份
- 交互式确认
- 恢复验证

## 5. 问题与风险

### 遇到的问题
- 无

### 需要 PM 关注的事项

1. **SSL 证书**：需要为生产域名申请 SSL 证书
   - `quantfi.io`
   - `api.quantfi.io`

2. **GitHub Secrets**：需要在 GitHub 仓库设置以下 Secrets：
   - `DEPLOY_HOST` - 服务器地址
   - `DEPLOY_USER` - SSH 用户名
   - `DEPLOY_SSH_KEY` - SSH 私钥
   - `SLACK_WEBHOOK_URL` - Slack 通知地址（可选）
   - `NEXT_PUBLIC_API_URL` - 前端 API 地址

3. **Dockerfile**：需要为 `apps/api` 和 `apps/web` 创建 Dockerfile
