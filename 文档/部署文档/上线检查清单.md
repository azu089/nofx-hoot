## 四、部署前准备

### 4.1 环境变量准备
```bash
# 必须配置的环境变量
DB_PASSWORD=<强密码>
JWT_SECRET=<至少32字符的随机字符串>
ENCRYPTION_KEY=<32字节加密密钥>

# 可选配置
ENABLE_BLOCKCHAIN_LISTENER=false
BSC_RPC_URL=https://bsc-dataseed1.binance.org
```

### 4.2 生成密钥命令
```bash
# 生成 JWT_SECRET
openssl rand -base64 32

# 生成 ENCRYPTION_KEY
openssl rand -hex 32

# 生成 DB_PASSWORD
openssl rand -base64 16
```

## 五、部署步骤

### 5.1 服务器准备
```bash
# 1. 安装 Docker
curl -fsSL https://get.docker.com | sh

# 2. 安装 Docker Compose
sudo apt install docker-compose-plugin

# 3. 克隆代码
git clone <repo-url> hoot
cd hoot
```

### 5.2 配置环境变量
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑环境变量
nano .env
```

### 5.3 启动服务
```bash
# 构建并启动
docker compose -f docker-compose.prod.yml up -d --build

# 查看状态
docker compose -f docker-compose.prod.yml ps

# 查看日志
docker compose -f docker-compose.prod.yml logs -f
```

### 5.4 验证部署
```bash
# 检查 API 健康状态
curl http://localhost:4001/api/health

# 检查前端
curl -I http://localhost:3001
```

## 六、回滚方案

### 6.1 快速回滚
```bash
# 停止服务
docker compose -f docker-compose.prod.yml down

# 切换到上一个版本
git checkout v2.1.0

# 重新启动
docker compose -f docker-compose.prod.yml up -d --build
```

### 6.2 数据库回滚
```bash
# 备份当前数据
docker exec hoot-postgres pg_dump -U hoot hoot > backup_$(date +%Y%m%d).sql

# 恢复备份
docker exec -i hoot-postgres psql -U hoot hoot < backup_YYYYMMDD.sql
```
