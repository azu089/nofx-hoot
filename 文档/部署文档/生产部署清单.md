## 1. 服务器准备

### 1.1 服务器要求

| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 50 GB SSD | 100 GB SSD |
| 系统 | Ubuntu 22.04 | Ubuntu 22.04 LTS |

### 1.2 基础软件安装

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 安装 Docker Compose
sudo apt install -y docker-compose-plugin

# 安装 AWS CLI（用于 S3 备份）
sudo apt install -y awscli

# 验证安装
docker --version
docker compose version
aws --version
```

## 2. 环境变量配置

### 2.1 必填变量

在服务器上创建 `.env` 文件：

```bash
cd /opt/hoot
cp .env.example .env
nano .env
```

**必须配置的变量：**

| 变量 | 说明 | 生成方式 |
|------|------|----------|
| `DB_PASSWORD` | 数据库密码 | `openssl rand -hex 16` |
| `JWT_SECRET` | JWT 签名密钥 | `openssl rand -hex 32` |
| `ENCRYPTION_KEY` | API Key 加密密钥 | `openssl rand -hex 32` |
| `WEBHOOK_SECRET` | Webhook 验签密钥 | `openssl rand -hex 32` |
| `TELEGRAM_BOT_TOKEN` | TG Bot Token | 从 @BotFather 获取 |
| `ADMIN_TG_ID` | 管理员 TG ID | Telegram 用户 ID |

### 2.2 S3 备份配置（推荐）

```bash
# AWS 凭证
AWS_ACCESS_KEY_ID=AKIAXXXXXXXXXXXXXXXX
AWS_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
S3_BUCKET=hoot-backups
S3_REGION=ap-southeast-1
```

### 2.3 生成安全密钥脚本

```bash
#!/bin/bash
echo "生成安全密钥..."
echo "DB_PASSWORD=$(openssl rand -hex 16)"
echo "JWT_SECRET=$(openssl rand -hex 32)"
echo "ENCRYPTION_KEY=$(openssl rand -hex 32)"
echo "WEBHOOK_SECRET=$(openssl rand -hex 32)"
```

## 3. 部署步骤

### 3.1 克隆代码

```bash
# 创建部署目录
sudo mkdir -p /opt/hoot
sudo chown $USER:$USER /opt/hoot
cd /opt/hoot

# 克隆代码
git clone https://github.com/your-org/hoot.git .
```

### 3.2 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑配置（填入实际值）
nano .env
```

### 3.3 执行部署

```bash
# 赋予脚本执行权限
chmod +x scripts/*.sh

# 执行完整部署
./scripts/deploy.sh deploy
```

### 3.4 配置定时任务

```bash
# 配置自动备份和监控
./scripts/deploy.sh setup-cron

# 验证定时任务
crontab -l
```

## 5. 常用运维命令

### 5.1 服务管理

```bash
# 查看状态
./scripts/deploy.sh status

# 查看日志
./scripts/deploy.sh logs          # 所有服务
./scripts/deploy.sh logs api      # 仅 API
./scripts/deploy.sh logs web      # 仅 Web

# 重启服务
./scripts/deploy.sh stop
./scripts/deploy.sh start

# 完整重新部署
./scripts/deploy.sh deploy
```

### 5.2 备份与恢复

```bash
# 手动备份
./scripts/deploy.sh backup

# 备份并上传 S3
./scripts/deploy.sh backup --upload-s3

# 查看备份
ls -la /var/backups/hoot/

# 恢复数据库（参见灾难恢复文档）

./scripts/deploy.sh monitor

# 带告警检查
./scripts/deploy.sh monitor --alert

# 查看监控日志
tail -f /var/log/hoot/monitor.log
```

## 6. 域名与 SSL 配置

### 6.1 使用 Nginx + Let's Encrypt

```bash
# 安装 certbot
sudo apt install -y certbot python3-certbot-nginx

# 配置 Nginx
sudo nano /etc/nginx/sites-available/hoot

# 申请证书
sudo certbot --nginx -d hoot.cool -d api.hoot.cool
```

### 6.2 Nginx 配置示例

```nginx
# /etc/nginx/sites-available/hoot
server {
    listen 80;
    server_name hoot.cool;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name hoot.cool;

    ssl_certificate /etc/letsencrypt/live/hoot.cool/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/hoot.cool/privkey.pem;

    location / {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

server {
    listen 443 ssl http2;
    server_name api.hoot.cool;

    ssl_certificate /etc/letsencrypt/live/hoot.cool/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/hoot.cool/privkey.pem;

    location / {
        proxy_pass http://localhost:4001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 7. 故障排查

### 7.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| API 无法启动 | 数据库连接失败 | 检查 DATABASE_URL 配置 |
| Web 502 错误 | API 未启动 | 先启动 API，再启动 Web |
| Bot 无响应 | Token 错误 | 检查 TELEGRAM_BOT_TOKEN |
| 备份失败 | S3 配置错误 | 检查 AWS 凭证和权限 |

### 7.2 日志位置

| 日志 | 位置 |
|------|------|
| API 日志 | `docker logs hoot-api` |
| Web 日志 | `docker logs hoot-web` |
| Bot 日志 | `docker logs hoot-telegram-bot` |
| 备份日志 | `/var/log/hoot/backup.log` |
| 监控日志 | `/var/log/hoot/monitor.log` |

参见：[灾难恢复文档](./灾难恢复.md)
