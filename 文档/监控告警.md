# HOOT 监控告警系统

> 本文档描述 HOOT 平台的监控和告警配置

---

## 健康检查端点

### API 服务 (NestJS)

| 端点 | 说明 | 认证 |
|------|------|------|
| `GET /health` | 完整健康检查 | 公开 |
| `GET /health/liveness` | 存活探针 | 公开 |
| `GET /health/readiness` | 就绪探针 | 公开 |
| `GET /health/metrics` | 系统指标 | 需认证 |
| `GET /health/stats` | 业务统计 | 需认证 |

### Web 服务 (Next.js)

| 端点 | 说明 |
|------|------|
| `GET /api/health` | 前端健康检查 |

## 健康检查响应示例

### 完整健康检查

```json
{
  "status": "healthy",
  "timestamp": "2025-01-30T10:00:00.000Z",
  "version": "1.0.0",
  "uptime": 3600,
  "services": {
    "database": {
      "status": "up",
      "latency": 5
    },
    "redis": {
      "status": "up",
      "latency": 2
    }
  }
}
```

### 状态说明

| 状态 | 说明 |
|------|------|
| `healthy` | 所有服务正常 |
| `degraded` | 部分服务异常但可用 |
| `unhealthy` | 核心服务不可用 |

## 监控脚本

### 简单监控脚本

```bash
#!/bin/bash
# scripts/monitor.sh

API_URL="${API_URL:-http://localhost:4001}"
WEB_URL="${WEB_URL:-http://localhost:3001}"

echo "=== HOOT 健康检查 ==="
echo "时间: $(date)"
echo ""

# 检查 API
echo "API 服务:"
api_status=$(curl -s -o /dev/null -w "%{http_code}" "$API_URL/health/liveness" 2>/dev/null)
if [ "$api_status" = "200" ]; then
  echo "  状态: ✅ 正常"
  api_health=$(curl -s "$API_URL/health" 2>/dev/null)
  echo "  详情: $api_health"
else
  echo "  状态: ❌ 异常 (HTTP $api_status)"
fi

echo ""

# 检查 Web
echo "Web 服务:"
web_status=$(curl -s -o /dev/null -w "%{http_code}" "$WEB_URL/api/health" 2>/dev/null)
if [ "$web_status" = "200" ]; then
  echo "  状态: ✅ 正常"
else
  echo "  状态: ❌ 异常 (HTTP $web_status)"
fi

echo ""
echo "=== 检查完成 ==="
```

### 使用方法

```bash
# 本地开发
./scripts/monitor.sh

# 指定地址
API_URL=https://api.hoot.com WEB_URL=https://hoot.com ./scripts/monitor.sh
```

## 告警配置（建议）

### 告警规则

| 告警 | 条件 | 严重程度 |
|------|------|---------|
| API 不可用 | `/health/liveness` 返回非 200 | 严重 |
| 数据库连接失败 | `services.database.status = down` | 严重 |
| Redis 连接失败 | `services.redis.status = down` | 警告 |
| 响应延迟过高 | 数据库延迟 > 100ms | 警告 |
| 内存使用过高 | `memory.heapUsed > 1GB` | 警告 |

### 通知渠道

- **Telegram**: 发送到运维群
- **邮件**: 发送到 ops@hoot.com
- **Webhook**: 集成到 PagerDuty/OpsGenie

## 链上监听状态

### 检查监听状态

```bash
curl -X GET http://localhost:4001/blockchain/status \
  -H "Authorization: Bearer <token>"
```

### 响应示例

```json
{
  "isConnected": true,
  "isListening": true,
  "monitoredTokens": ["USDT", "HOOT"]
}
```

---

## 启用链上监听

在 `.env` 中配置：

```bash
ENABLE_BLOCKCHAIN_LISTENER=true
BSC_RPC_URL=https://bsc-dataseed1.binance.org
USDT_CONTRACT_ADDRESS=0x55d398326f99059fF775485246999027B3197955
HOOT_CONTRACT_ADDRESS=<你的HOOT代币地址>
```

重启 API 服务后生效。

## 日志配置

### 日志级别

| 级别 | 说明 |
|------|------|
| error | 错误，需要立即处理 |
| warn | 警告，需要关注 |
| info | 一般信息 |
| debug | 调试信息（生产环境关闭） |

### 日志格式

```json
{
  "timestamp": "2025-01-30T10:00:00.000Z",
  "level": "info",
  "context": "WalletService",
  "message": "用户充值成功",
  "userId": "xxx",
  "amount": "100.00",
  "txHash": "0x..."
}
```

### Docker 日志

```yaml
logging:
  driver: "json-file"
  options:
    max-size: "10m"
    max-file: "3"
```
