## 第一步：配置 DNS（在 Spaceship）

1. 登录 https://www.spaceship.com
2. 进入 **Domains** → 找到 **tizo.cc** → 点击 **DNS**
3. 添加以下 3 条 A 记录：

| Type | Host | Value | TTL |
|------|------|-------|-----|
| A | @ | 165.245.176.139 | 3600 |
| A | www | 165.245.176.139 | 3600 |
| A | api | 165.245.176.139 | 3600 |

4. 保存后等待 5-10 分钟生效

**验证方法**（在本地终端运行）：
```bash
ping tizo.cc
ping api.tizo.cc
```
看到返回 165.245.176.139 就说明 DNS 生效了。

## 第三步：在服务器上运行部署脚本

### 3.1 下载项目代码

在服务器上运行：
```bash
# 安装 git（如果没有）
apt update && apt install -y git

# 克隆代码（替换为你的仓库地址）
# 如果是私有仓库，需要配置 SSH Key 或使用 HTTPS + Token
git clone https://github.com/YOUR_USERNAME/quantfi.git /opt/quantfi

# 或者使用 rsync 从本地上传（在本地终端运行）：
# rsync -avz --exclude node_modules --exclude .git /Users/azu/主QuantFi/ root@165.245.176.139:/opt/quantfi/
```

### 3.2 运行环境安装脚本

```bash
cd /opt/quantfi
chmod +x scripts/deploy-production.sh
./scripts/deploy-production.sh
```

这个脚本会自动安装：
- Docker
- Node.js 20
- pnpm
- PM2
- Nginx
- Certbot

### 3.3 启动服务

```bash
chmod +x scripts/start-services.sh
./scripts/start-services.sh
```

这个脚本会：
- 启动 PostgreSQL 和 Redis
- 安装项目依赖
- 执行数据库迁移
- 构建项目
- 用 PM2 启动前后端

---

## 第四步：配置 SSL 证书

DNS 生效后，运行：
```bash
sudo certbot --nginx -d tizo.cc -d www.tizo.cc -d api.tizo.cc
```

按提示操作：
1. 输入邮箱（用于证书到期提醒）
2. 同意条款：输入 `Y`
3. 是否分享邮箱：输入 `N`

完成后 Certbot 会自动修改 Nginx 配置，启用 HTTPS。

## 常用命令

### 查看服务状态
```bash

```

```bash

# 前端日志

```

### 重启服务
```bash
pm2 restart all
```

### 查看数据库
```bash
docker exec -it quantfi-postgres psql -U quantfi -d quantfi
```

### 查看 Redis
```bash
docker exec -it quantfi-redis redis-cli -a 'Qf2026!Tizo#Secure'
```

## 故障排查

### 网站打不开
```bash
# 检查 Nginx
sudo nginx -t
sudo systemctl status nginx

# 检查 PM2
pm2 status
pm2 logs
```

### 数据库连接失败
```bash
# 检查 Docker 容器
docker compose ps
docker compose logs postgres
```

### SSL 证书问题
```bash
# 查看证书状态
sudo certbot certificates

# 手动续期
sudo certbot renew
```
