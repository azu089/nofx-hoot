## 1.1 HOOT 是什么

### Q: HOOT / Hoot 是什么平台？
**A:** HOOT 是一个 AI 驱动的**非托管**量化交易平台，将机构级的量化策略带给每一位普通用户。

**核心特点：**
- **AI 驱动决策** — 支持极速（Solo）、共识（Debate）、深研（Research）、网格（Grid）四种 AI 交易模式
- **非托管架构** — 你的资金始终留在自己的交易所账户（如 Binance 合约账户），HOOT 通过 API 仅执行交易指令，**无法提现或转移你的资金**
- **燃油费模式** — 只有盈利的交易才收费（Free 用户 25%，Pro 会员 20%），亏损交易一分不收
- **多角色辩论系统** — 行业独创，多个 AI 角色辩论后投票决策
- **注册即送 20 HOOT 代币**

### Q: HOOT 和其他交易平台有什么不同？
**A:** HOOT 的核心差异：
1. **非托管** — 不碰你的钱，资金在你自己的交易所
2. **AI 自动交易** — 不需要盯盘，AI 7×24 小时运行
3. **只赚才收费** — 亏了不收你一分钱
4. **多 AI 辩论** — 不是单个 AI 拍脑袋，而是多角色交叉验证

### Q: HOOT 安全吗？
**A:** HOOT 采用行业最安全的非托管架构：
- 你的资金**始终在你自己的交易所**（如 Binance），不存在跑路风险
- API Key 使用 **AES-256-GCM 军事级加密**存储
- API 权限仅开「交易」，**禁止开「提现」**
- 密钥仅在服务器内存中短暂解密用于下单，永不明文落地

## 1.2 注册账户

### Q: 怎么注册 HOOT 账户？
**A:** HOOT 支持三种注册方式：

**方式一：邮箱注册（推荐新手）**
1. 访问 HOOT 官网或打开 App
2. 点击「注册」
3. 输入邮箱地址（建议用常用邮箱接收交易通知）
4. 设置密码（至少 8 位，包含字母和数字）
5. 填写邀请码（如有，双方各得奖励）
6. 查收邮件验证码并完成验证
7. 注册成功，自动到账 **20 HOOT** 新人奖励

**方式二：Web3 钱包登录**
- 支持 MetaMask、WalletConnect、Coinbase Wallet 等
- 点击「钱包登录」→ 连接钱包 → 签名验证（无需 Gas）

**方式三：Telegram 登录**
- 打开 @HootCool_bot → 发送 /start → 自动完成注册

### Q: 注册有奖励吗？
**A:** 有的！
- **注册** → 立即到账 **20 HOOT**
- **绑定 Telegram** → 再得 **10 HOOT**
- **绑定钱包** → 再得 **10 HOOT**
- **填邀请码** → 双方各得奖励

### Q: 忘记密码怎么办？
**A:** 在登录页点击「忘记密码」→ 输入注册邮箱 → 收验证码 → 设置新密码。

## 1.3 绑定交易所

### Q: 怎么绑定 Binance？
**A:** 绑定 Binance 合约 API Key 步骤：

1. 登录 Binance 官网 → 头像 → 「API 管理」
2. 点「创建 API」→ 选「系统生成」
3. 命名（如：Hoot-Trading）→ 完成安全验证
4. **权限设置（关键）：**
   - ✅ 开启：读取权限
   - ✅ 开启：合约交易权限（Enable Futures）
   - ❌ **禁止：提现权限（必须关闭！）**
5. 复制 API Key 和 Secret Key
6. 进入 HOOT → 钱包 → 交易所 → 添加 → 选 Binance 合约 → 粘贴 → 测试连接

### Q: 支持哪些交易所？
**A:** HOOT 支持 **6 个 CEX + 3 个 DEX**：

**CEX（中心化交易所）：**
| 交易所 | 认证方式 |
|--------|---------|
| Binance | API Key + Secret |
| OKX | API Key + Secret + **交易密码（Passphrase）** |
| Bybit | API Key + Secret |
| Gate.io | API Key + Secret |
| Bitget | API Key + Secret |
| Coinbase | API Key + Secret |

**DEX（去中心化交易所）：**
| 交易所 | 认证方式 |
|--------|---------|
| Hyperliquid | 钱包地址 + Agent 私钥 |
| Lighter | 钱包地址 + 私钥 + API Key |
| Aster | 主钱包 + 签名钱包 + 私钥 |

### Q: OKX 怎么绑定？
**A:** OKX 比 Binance 多一个**交易密码（Passphrase）**：
1. 登录 OKX → 设置 → API → 创建 API Key
2. 设置 API 名称和交易密码（Passphrase）
3. 权限：✅ 交易 ❌ 提现
4. 在 HOOT → 钱包 → 交易所 → 添加 OKX
5. 填入 API Key + Secret + **Passphrase**
6. 测试连接

### Q: Bybit 怎么绑定？
**A:** 和 Binance 类似：
1. 登录 Bybit → 账户 → API 管理 → 创建
2. 权限：✅ 合约交易 ❌ 提现
3. 在 HOOT 添加 Bybit → 粘贴 API Key + Secret → 测试连接

### Q: DEX（Hyperliquid/Lighter/Aster）怎么连接？
**A:** DEX 使用钱包连接而非 API Key：
1. 在 HOOT → 钱包 → 交易所 → 选择 DEX 交易所
2. 连接你的 Web3 钱包
3. 签名授权（不需要 Gas）
4. 连接成功后即可使用 AI 交易

DEX 的优势：无需 API Key、无需信任中心化交易所、链上透明。

### Q: API Key 权限怎么设置最安全？
**A:**
- ✅ 只开「读取」+「合约交易」
- ❌ **一定不要开「提现」权限**
- 建议绑定 IP 白名单，限制只有 HOOT 服务器可用
- 如怀疑泄露，立即在交易所删除 Key 并重新创建

### Q: 可以绑定多个交易所吗？
**A:** 可以。你可以同时绑定多个交易所的 API Key，不同 AI 策略可以绑定不同的交易所。

## 1.4 第一笔 AI 交易

### Q: 怎么开始第一笔 AI 交易？
**A:**
1. 进入首页 → 点「开始交易」或「AI 交易」
2. **选模式：** 新手推荐「极速模式」
3. **选交易对：** 建议从 BTC/USDT 或 ETH/USDT 开始
4. **配风控参数：**
   - 杠杆：新手建议 2-3x
   - 止损：建议 10-20%
   - 最小投入金额
5. 点「启动策略」
6. AI 开始自动分析并交易

### Q: 最少需要多少钱？
**A:** 建议 **$100 USDT** 起步体验。太少的话手续费会侵蚀收益。首次建议用 $100-500 USDT 小额试水，观察 1-3 天了解策略运作逻辑，确认匹配自己的风险承受能力后再增加资金。

### Q: 用什么模式开始比较好？
**A:**
- **完全新手** → 极速模式（最简单、快速体验）
- **追求稳健** → 网格模式（震荡行情自动赚钱）
- **想要更准** → 共识模式（多 AI 投票降低误判）
- **资金较多** → 深研模式（多角色辩论最严谨）

## 1.5 TG Bot 使用指南

### Q: HOOT TG Bot 有哪些功能？
**A:** 在 Telegram 中搜索 @HootCool_bot，支持以下命令：

| 命令 | 功能 |
|------|------|
| `/start` | 开始使用 + 绑定邀请码 |
| `/wallet` | 查看余额和持仓统计 |
| `/trade` | 查看交易历史和执行日志 |
| `/checkin` | 每日签到领 HOOT |
| `/invite` | 查看邀请码和返佣信息 |
| `/closeall` | 紧急平仓所有持仓 |
| `/help` | 帮助菜单 |
| `/bind [code]` | 绑定网站账户 |
| `/lang [cn/en]` | 切换语言 |

### Q: TG Bot 和网页有什么区别？
**A:** TG Bot 提供快速操作入口（查余额、签到、平仓等），完整功能建议使用网页版。Bot 还会推送实时交易通知（开仓、平仓、风控告警）。

## 1.6 绑定 Telegram

### Q: 怎么绑定 Telegram 账号？
**A:** 两种方式：

**方式一：从网页绑定**
1. 登录 HOOT 网页 → 设置 → Telegram 绑定
2. 扫码或点击链接连接 TG 账号

**方式二：从 TG Bot 绑定**
1. 先用邮箱注册 HOOT 账户
2. 在 @HootCool_bot 中发送 `/bind` + 你的绑定码
3. 绑定成功后两个账户合并

### Q: 绑定 TG 有什么好处？
**A:**
- 获赠 **10 HOOT** 代币
- 接收实时交易通知（开仓/平仓/风控告警）
- 在 TG 中快速查余额、签到、平仓
- 使用 Mini App 快捷操作
