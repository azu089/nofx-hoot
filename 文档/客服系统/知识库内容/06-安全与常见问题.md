## 6.1 资金安全保障

### Q: 我的钱安全吗？
**A:** HOOT 采用**非托管架构**，这是行业最安全的设计：

1. **资金在你自己的交易所** — 你的钱始终在 Binance/OKX 等交易所的合约账户中，HOOT 不持有你的任何资金
2. **API 无提现权限** — 绑定 API 时必须关闭「提现」权限，HOOT 只能下单交易，无法转走你的钱
3. **军事级加密** — API Key 使用 AES-256-GCM 加密存储，密钥仅在内存中短暂解密
4. **没有跑路风险** — 即使 HOOT 停止运营，你的资金仍安全在你自己的交易所

### Q: HOOT 能不能偷我的钱？
**A:** **不能。** 因为：
- API 权限只有「交易」没有「提现」→ 物理上无法转走你的资金
- 你可以随时在交易所删除 API Key → HOOT 立即失去所有操作权限
- 你可以随时登录交易所查看所有交易记录，完全透明

### Q: 如果 HOOT 被黑了怎么办？
**A:** 即使发生最坏情况：
- 黑客拿到加密的 API Key → 需要破解 AES-256-GCM（实际不可能）
- 即使破解了 → API 没有提现权限 → 无法转走你的钱
- 你可以立即在交易所删除 API Key 止损

## 6.2 API Key 安全

### Q: API Key 是什么？
**A:** API Key 是交易所提供的"钥匙"，让 HOOT 可以代替你下单交易。类似于给别人一把只能开门但不能拿东西的钥匙。

### Q: API Key 安全最佳实践？
**A:**
1. ❌ **绝对不开「提现」权限** — 这是最重要的一条
2. ✅ 只开「读取」+「合约交易」权限
3. ✅ 绑定 IP 白名单（限制只有 HOOT 服务器可用）
4. ✅ 不在任何非官方渠道分享 API Key
5. ✅ 定期检查 API Key 的使用记录
6. ✅ 怀疑泄露时立即删除并重新创建

### Q: API Key 泄露了怎么办？
**A:** 立即执行：
1. 登录交易所 → API 管理 → **删除该 API Key**
2. 在 HOOT 中删除绑定
3. 创建新的 API Key 并重新绑定
4. 检查交易所最近是否有异常交易记录

## 6.3 风控与止损

### Q: HOOT 有哪些风控保护？
**A:** 多重风控机制：

1. **AI 止损** — AI 判断行情不利时主动平仓
2. **硬止损** — 亏损达到设定比例（如 10%）自动平仓
3. **保证金率监控** — 保证金率过低时预警/平仓
4. **最大仓位限制** — 限制同时持有的仓位数量
5. **杠杆上限** — 限制最大杠杆倍数
6. **紧急平仓** — `/closeall` 一键全部平仓

### Q: 亏了怎么办？
**A:**
1. **止损保护** — AI 和硬止损会自动控制最大亏损
2. **紧急平仓** — 随时可以 `/closeall` 全部平仓
3. **暂停策略** — 在 AI 交易页面暂停策略，不再开新仓
4. **调整参数** — 降低杠杆、缩小仓位、收紧止损

**重要提醒：**
- 量化交易有亏损风险，过去业绩不代表未来收益
- 建议只用闲钱参与，不要使用生活必需资金
- 小额起步（$100-500），确认匹配风险偏好后再增加

### Q: HOOT 保证盈利吗？
**A:** **不保证。** 任何量化交易都有亏损风险。HOOT 提供 AI 辅助决策和多重风控保护，但不能消除市场风险。我们的核心承诺是：**亏损不收费（燃油费模式）+ 非托管安全架构**。

## 6.4 常见报错排查

### Q: API 连接失败怎么办？
**A:** 常见原因和解决方案：

1. **API Key 过期或被删除**
   → 在交易所检查 API Key 是否仍然有效，必要时重新创建

2. **权限设置不对**
   → 确认开启了「读取」+「合约交易」权限

3. **IP 白名单限制**
   → 如果设了 IP 白名单，确认包含 HOOT 服务器 IP

4. **交易所维护中**
   → 检查交易所公告是否在维护，等待恢复

5. **网络问题**
   → 稍后重试，如持续失败联系客服

### Q: 下单失败怎么办？
**A:** 常见原因：
- **余额不足** — 交易所合约账户 USDT 不够
- **保证金不足** — 杠杆过高导致需要的保证金超过可用额度
- **最小下单量** — 交易对有最小下单金额限制
- **交易所限制** — 部分交易对可能暂停交易

### Q: 策略一直不开仓怎么回事？
**A:** AI 不是每时每刻都会开仓，可能的原因：
- **行情不适合** — AI 判断当前没有好的交易机会
- **共识未达成** — 共识模式中多数 AI 选择观望
- **风控限制** — 仓位已满或保证金使用率过高
- **策略暂停** — 检查策略是否处于暂停状态

这是正常现象，等待行情变化即可。频繁开仓不一定好，AI 会选择最佳时机。

## 6.6 故障排查大全

### Q: 策略运行中显示"暂停"是怎么回事？
**A:** AI 策略可能因以下原因自动暂停：
1. **趋势突破** — AI 检测到单边行情，暂停网格避免逆势操作
2. **风控触发** — 日内亏损或最大回撤达到上限
3. **交易所异常** — API 连接中断或交易所维护
4. **余额不足** — 合约账户保证金不够开新仓

**处理方式：** 查看策略日志中的暂停原因。如果是行情判断暂停，等待 AI 自动恢复即可。

### Q: 网格层显示"—"是什么意思？
**A:** 通常有两种原因：
1. **总仓位上限触及** — 总投资 × 杠杆已用尽，系统保护性跳过剩余层
2. **低于最小下单量** — 单层金额低于交易所要求（BTC 约 $100，SOL 约 $5）

**解决方案：** 增加资金、减少层数、或降低杠杆。

### Q: 通知收不到怎么办？
**A:**
1. 确认已绑定 Telegram（网页 → 设置 → TG 绑定）
2. 确认没有屏蔽 @HootCool_bot
3. 在 TG 中给 Bot 发 `/start` 确保会话激活
4. 检查 TG 通知设置是否开启
5. 如仍有问题，尝试解绑后重新绑定

### Q: 绑定交易所后余额显示 0？
**A:**
1. 确认资金在**合约账户**（不是现货账户）
2. 在交易所内从现货 → 划转 → 合约
3. 等待 1 分钟后刷新 HOOT 页面
4. 如仍为 0，检查 API Key 是否有"读取"权限

### Q: 注册后一直没收到验证邮件？
**A:**
1. 检查垃圾邮件/促销邮件文件夹
2. 确认邮箱地址输入正确
3. 点击"重新发送验证邮件"
4. 如仍未收到，尝试使用其他邮箱注册
5. 或直接使用 Web3 钱包/Telegram 方式注册

### Q: 页面加载很慢/打不开？
**A:**
1. 检查网络连接是否正常
2. 清除浏览器缓存后重试
3. 尝试使用其他浏览器（推荐 Chrome/Safari）
4. 如在国内，可能需要科学上网
5. 如持续打不开，可能平台在维护，查看 TG 公告频道 @hoot_ann

### Q: 怎么修改密码？
**A:** 网页 → 个人设置 → 安全 → 修改密码。需要输入旧密码和新密码。如果忘记密码，在登录页点击"忘记密码"通过邮箱重置。

### Q: 怎么删除/注销账户？
**A:** 联系人工客服处理。发邮件到 support@hoot.trade，说明你要注销账户和原因。注销前请确保：
1. 所有策略已停止
2. 所有持仓已平仓
3. 平台余额已提现
4. 交易所 API Key 已删除
