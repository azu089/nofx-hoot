## 技术实现

### 文件清单
- `apps/web/src/components/ui/checkbox.tsx` - Checkbox 组件
- `apps/web/src/components/ui/index.ts` - 组件导出（已更新）
- `apps/web/src/app/(auth)/forgot-password/page.tsx` - 忘记密码页
- `apps/web/src/app/(dashboard)/settings/blacklist/page.tsx` - 币种黑名单页

### 依赖的组件
- Button, Input, Card - 基础 UI 组件
- react-hook-form + zod - 表单验证
- lucide-react - 图标库
- useToast - 消息提示

### API 调用（模拟）
忘记密码页面预留了 3 个 API 调用点：
- `POST /api/auth/forgot-password/send-code` - 发送验证码
- `POST /api/auth/forgot-password/verify-code` - 验证验证码
- `POST /api/auth/forgot-password/reset` - 重置密码

币种黑名单页面预留了 1 个 API 调用点：
- `PATCH /api/strategies/configs/:id` - 更新黑名单配置

## 风险点与注意事项

### 风险点
1. **忘记密码流程**
   - 验证码倒计时仅为前端计时，刷新页面会重置
   - 未实现真实的邮件发送和验证码验证
   - 密码强度仅为前端检测，不影响后端存储

2. **币种黑名单**
   - 币种列表为硬编码，未从后端获取
   - 未实现真实的 API 保存
   - 预设的高风险币种需要与后端配置一致

### 注意事项
- 两个页面均使用模拟数据，需要后端 API 完成后对接
- Toast 提示已集成，但需要确保页面外层有 `ToastProvider`
- 响应式布局已实现，建议在不同屏幕尺寸测试
