# HOOT AI 模块 — UI 线框图设计 v2（极简流畅版）

> 设计原则：**极简流畅** — 一屏一任务、预设优于手动、减少认知负担
> 基于实际后端 22 个 API 端点 + 前端现有设计系统
> 深色主题 (#0A0A0F)、移动优先、与现有 Dashboard 风格一致

---

## 导航结构

现有 5 项底部导航不变，AI 入口作为**子页面**通过 Dashboard 卡片进入：

```
底部导航（不变）：Home | Strategies | Trading | Wallet | Profile

AI 入口方式：
  ├─ Dashboard 首页 "AI 研究" + "AI 策略" 双卡片入口
  └─ Settings > AI 设置
```

## 七、极简设计原则清单

1. **一屏一任务**：A1 研究入口只做"选币+选深度+开始"三件事
2. **预设优于手动**：B2 用三个预设卡片（保守/均衡/激进）替代 8+8 个控件
3. **渐进式披露**：Settings 折叠态只显示摘要，B2 自定义参数默认折叠
4. **信息分层**：B1 策略列表和排行榜用 Tab 分离
5. **操作即结果**：点击"开始研究"立即跳转进度页，无多余确认
6. **颜色即语义**：绿=盈利/做多、红=亏损/做空、灰=等待/停止、黄=暂停/警告
