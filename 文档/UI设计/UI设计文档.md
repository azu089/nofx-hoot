# QuantFi UI 设计文档 v3.0

> **设计理念**：Web3 原生 · 有活力 · 代币驱动 · 久看不累
> **核心定位**：不只是交易工具，是代币生态参与入口

---

## 一、设计哲学

### 1.1 与 v2.0 的核心差异

| 维度 | v2.0（工具感） | v3.0（生态感） |
|------|---------------|---------------|
| 视觉风格 | 暗黑极简 | 暗黑 + 渐变活力 |
| 核心焦点 | 交易数据 | 资产 + 生态参与 |
| 色彩情绪 | 冷静克制 | 沉稳中带活力 |
| 代币地位 | 附属功能 | 核心驱动力 |
| 信息密度 | 偏高 | 精简聚焦 |

### 1.2 设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   1. 少即是多                                                │
│      只展示用户此刻需要的信息，其他折叠或下钻                 │
│                                                             │
│   2. 代币为先                                                │
│      QFI 代币贯穿全站，每个动作都能看到代币激励              │
│                                                             │
│   3. 情绪正向                                                │
│      盈利时庆祝，亏损时温和，整体氛围积极                    │
│                                                             │
│   4. 呼吸感                                                  │
│      大留白，舒适间距，眼睛不累                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 字体规范

```
字体家族：
├── 英文数字：Inter（干净现代）
├── 中文：思源黑体 / PingFang SC
└── 等宽数字：JetBrains Mono（金额显示）

字号系统（遵循 8px 基准）：
├── 超大数字    56px / 40px     资产总额
├── 大数字      32px / 24px     卡片主数据
├── 标题        20px / 18px     页面/区块标题
├── 正文        15px / 14px     主要内容
├── 辅助        13px / 12px     次要说明
└── 微小        11px            标签、徽章

行高：1.5（正文）/ 1.2（数字）
```

### 2.3 间距与圆角

```
间距系统（8px 基准）：
├── xs    4px      紧凑元素内
├── sm    8px      元素内部
├── md    16px     元素之间
├── lg    24px     区块之间
├── xl    32px     大区块之间
└── 2xl   48px     页面边距

圆角系统：
├── 小      8px     按钮、输入框
├── 中      12px    卡片
├── 大      16px    弹窗
└── 全圆    9999px  标签、头像
```

### 2.4 动效规范

```
基础动效：
├── 过渡时长    200ms（快）/ 300ms（标准）/ 500ms（慢）
├── 缓动曲线    cubic-bezier(0.4, 0, 0.2, 1)
└── 悬停效果    轻微上浮 + 光晕增强

特殊动效：
├── 数字变化    CountUp 动画，1s 内完成
├── 盈利庆祝    绿色粒子 + 轻微弹跳
├── 加载状态    骨架屏 + 品牌色光晕脉动
└── 页面切换    Fade + 轻微上移
```

## 六、组件规范

### 6.1 按钮

```
主按钮（CTA）
├── 背景：品牌渐变 (#06B6D4 → #8B5CF6)
├── 文字：白色
├── 圆角：8px
├── 高度：48px（桌面）/ 44px（移动）
└── 悬停：亮度提升 + 轻微上浮

次要按钮
├── 背景：透明
├── 边框：1px solid #2A2A3A
├── 文字：#F8F8FC
├── 悬停：背景变为 rgba(255,255,255,0.05)

危险按钮
├── 背景：#F43F5E（实心）或 透明 + 红色边框
├── 文字：白色 或 #F43F5E
└── 用于：平仓、删除等操作
```

### 6.2 卡片

```
标准卡片
├── 背景：#12121A
├── 边框：1px solid #1E1E2E
├── 圆角：12px
├── 内边距：20px（桌面）/ 16px（移动）
└── 悬停：边框变为 rgba(139,92,246,0.3)

高亮卡片（资产、代币）
├── 背景：渐变光晕
├── 边框：1px solid rgba(139,92,246,0.3)
└── 用于：重要数据展示
```
