# QuantFi UI 优化方案 v3.3

> 基于用户反馈 + 同类平台研究（3Commas、Bitget、Pionex）
> 目标：清晰、简洁、无重复数据、功能易达

---

## 一、核心问题诊断

| # | 问题 | 影响 |
|---|------|------|
| 1 | 导航 6 Tab 较多 | 认知负担重 |
| 2 | 首页数据堆砌 | 不知道干什么 |
| 3 | 仪表盘/持仓/我的 数据重复 | 信息冗余 |
| 4 | 持仓缺少日期筛选、现货/合约区分 | 功能不完整 |
| 5 | 资产页缺账单、点卡、兑换 | 功能缺失 |
| 6 | 策略管理/配置页面缺失 | 核心功能遗漏 |
| 7 | 生态缺质押/分红记录 | 功能不完整 |
| 8 | 移动端卡片过大 | 空间浪费 |
| 9 | 我的页面子页面未设计 | UI不完整 |

## 二、导航结构重构

### 2.1 桌面端侧边栏（5 项，精简后）

```
┌────────────────────┐
│  QuantFi Logo      │
├────────────────────┤
│  🏠 首页           │  ← 快捷入口 + 账户概览
│  📈 交易           │  ← 持仓 + 历史 + 信号
│  ⚡ 策略           │  ← 市场 + 我的 + 管理
│  💰 资产           │  ← 余额 + 账单 + 兑换
│  👤 我的           │  ← 个人设置 + 生态
├────────────────────┤
│  ⚙️ 设置           │
│  ❓ 帮助           │
└────────────────────┘
```

### 2.2 移动端底部导航（5 Tab）

```
┌─────────────────────────────────────────────────┐
│                   页面内容                       │
├─────────────────────────────────────────────────┤
│  [首页]   [交易]   [策略]   [资产]   [我的]     │
│   🏠       📈       ⚡       💰       👤       │
└─────────────────────────────────────────────────┘
```

**对比同类平台**：
- Binance App: 5 Tab（首页/市场/交易/合约/资产）
- Bitget App: 5 Tab（首页/行情/跟单/合约/资产）
- 3Commas: 侧边 5 项（Dashboard/Bots/Terminal/Marketplace/Account）

**结论：5 Tab 是行业标准，符合用户习惯**

## 三、页面职责重新划分（消除重复）

### 3.1 数据归属原则

| 数据类型 | 应该在哪里看 | 不应该在哪里 |
|---------|-------------|-------------|
| 总资产/今日盈亏 | 首页（概览） | ~~持仓页~~ ~~我的页~~ |
| 当前持仓列表 | 交易页 | ~~首页~~ |
| 策略运行状态 | 策略管理页 | ~~首页~~ ~~我的页~~ |
| 邀请人数/佣金 | 邀请页（我的子页） | ~~我的页统计~~ |
| 累计收益 | 首页/资产页 | ~~我的页~~ |
| 订阅策略数 | 策略管理页 | ~~我的页~~ |

### 3.2 各页面核心职责

| 页面 | 核心职责 | 展示内容 |
|------|---------|---------|
| **首页** | 快速入口 + 账户快照 | 资产卡片 + 4个快捷入口 + 公告 |
| **交易** | 持仓管理 + 交易执行 | 持仓列表 + 历史 + 信号 + 日志 |
| **策略** | 策略发现 + 策略管理 | 市场 + 我的订阅 + 我创建的 |
| **资产** | 资金管理 | 余额 + 账单 + 充提 + 兑换 |
| **我的** | 账户设置 + 附属功能 | 设置 + 邀请 + 安全 + 生态入口 |

```
│   │                                                     │  │
│   │    今日 +$234.56 (+1.9%)                            │  │
│   │                                                     │  │
│   └─────────────────────────────────────────────────────┘  │
│                                                             │
│   快捷入口                                                   │
│   ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐          │

│   └─────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**首页内容清单**：
1. 资产卡片（总资产 + 今日盈亏）
2. 4个快捷入口（交易/策略/充值/绑定API）
3. 运行状态条（策略数/持仓数/交易数）
4. 公告/通知
5. 可选：最近信号（3条）

**不放在首页**：
- ❌ 持仓列表（去交易页）
- ❌ 策略列表（去策略页）
- ❌ 复杂图表（去专业页面）

## 五、移动端优化

### 5.1 卡片密度优化

**问题**：当前一个数据占一整个卡片，浪费空间

**优化方案**：使用紧凑布局

```
原设计（浪费空间）:
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│             │  │             │  │             │
│   +$1,234   │  │      3      │  │     12      │
│   累计收益   │  │   订阅策略  │  │   邀请好友  │
│             │  │             │  │             │
└─────────────┘  └─────────────┘  └─────────────┘

优化后（紧凑）:
┌─────────────────────────────────────────────────┐
│  +$1,234 累计收益  ·  3 策略  ·  5 持仓        │
└─────────────────────────────────────────────────┘

或者横向滚动卡片:
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│+$1,234 │ │ 3 策略 │ │ 5 持仓 │ │ 12 邀请│
│累计收益│ │ 运行中 │ │ 进行中 │ │ 好友   │
└────────┘ └────────┘ └────────┘ └────────┘
     ← 可横向滚动 →
```

### 5.2 移动端页面映射

| 桌面端页面 | 移动端对应 | 入口 |
|-----------|-----------|------|
| 首页 | MobileDashboard | 底部 Tab |
