### 2.2 策略回测页面 `/backtest`

#### 功能定位
- 配置策略参数（支持 3 种来源）
  1. 策略市场的策略（带预设参数）
  2. 代码策略（上传 .py 文件）
  3. 自定义策略（纯参数配置）
- 运行回测，查看结果
- 保存到「我的策略」开始使用

#### URL 参数
- `/backtest` - 空白配置
- `/backtest?strategyId=xxx` - 预填策略市场的策略
- `/backtest?mode=code` - 代码策略模式

## 五、API 端点清单

### 5.1 策略市场相关

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/strategies` | 获取策略列表（支持筛选排序） |
| GET | `/strategies/:id` | 获取策略详情 |
| GET | `/strategies/:id/performance` | 获取策略历史表现 |

### 5.2 策略回测相关

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/strategies/backtest` | 执行回测 |
| GET | `/strategies/backtest/:id` | 获取回测结果 |
| GET | `/strategies/backtest/history` | 获取回测历史 |

### 5.3 策略配置相关

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/strategies/my/configs` | 获取我的策略配置 |
| POST | `/strategies/configs` | 保存策略配置 |
| PUT | `/strategies/configs/:id` | 更新策略配置 |
| DELETE | `/strategies/configs/:id` | 删除策略配置 |

### 5.4 策略上传相关

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/strategies/my/uploads` | 获取我上传的策略 |
| POST | `/strategies/upload` | 上传新策略 |
| PUT | `/strategies/:id` | 更新策略信息 |
| DELETE | `/strategies/:id` | 删除策略（仅草稿） |
| POST | `/strategies/:id/start-backtest` | 启动回测 |
| POST | `/strategies/:id/start-trial` | 启动试运行 |
| GET | `/strategies/:id/trial-status` | 获取试运行状态 |
| POST | `/strategies/:id/submit-review` | 提交审核 |

### 5.5 收益相关

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/strategies/my/revenue` | 获取收益汇总 |
| GET | `/strategies/my/revenue/details` | 获取收益明细 |
| POST | `/strategies/revenue/withdraw` | 提现收益 |
