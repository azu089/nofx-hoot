## 一、一级导航结构（通用版）

### 1.1 导航模式选择

**推荐方案：响应式双模式导航**

| 设备类型 | 导航模式 | 说明 |
|---------|---------|------|
| 移动端 (< 1024px) | **底部 Tab Bar (5 个)** | 固定底部，始终可见 |
| 桌面端 (≥ 1024px) | **左侧边栏 (可折叠)** | 固定左侧，支持折叠/展开 |

**设计理念**：
- 移动端采用「少即是多」原则，5 个 Tab 覆盖核心场景
- 桌面端采用「渐进披露」原则，分组折叠减少认知负担
- 两端入口命名、图标保持一致，降低用户迁移成本

### 1.2 移动端底部导航（5 Tab）

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                      [ 页面内容区 ]                          │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  🏠        📈        ⚡        💰        👤                 │
│ 首页      交易      策略      资产      我的                │
└─────────────────────────────────────────────────────────────┘
```

#### Tab 1：首页 (Home)

| 属性 | 内容 |
|-----|------|
| **图标** | Home (房子) |
| **路由** | `/dashboard` |
| **核心职责** | 展示资产总览、收益趋势、运行状态，提供快捷入口 |
| **只负责** | 数据概览、状态监控、快捷跳转 |
| **不负责** | 具体操作（交易、充值、配置等具体动作） |
| **主要模块** | 资产卡片、收益曲线、机器人状态卡、VPS 状态卡、公告横幅 |

#### Tab 2：交易 (Trade)

| 属性 | 内容 |
|-----|------|
| **图标** | TrendingUp (趋势线) |
| **路由** | `/trading` |
| **核心职责** | 实盘交易控制、K 线查看、日志监控、VPS 管理 |
| **只负责** | 交易执行、状态监控、日志查看 |
| **不负责** | 策略选择（去策略 Tab）、资金操作（去资产 Tab） |
| **主要模块** | 策略运行状态、K 线图、交易日志流、VPS 实例入口、回测入口 |

#### Tab 3：策略 (Strategy)

| 属性 | 内容 |
|-----|------|
| **图标** | Zap (闪电) |
| **路由** | `/strategies` |
| **核心职责** | 浏览策略市场、管理我的策略、上传策略 |
| **只负责** | 策略发现、策略配置、策略管理 |
| **不负责** | 策略执行（去交易 Tab）、收益查看（去首页或我的） |
| **主要模块** | 策略卡片列表、筛选器、我的配置入口、上传入口 |

#### Tab 4：资产 (Assets)

| 属性 | 内容 |
|-----|------|
| **图标** | Wallet (钱包) |
| **路由** | `/wallet` |
| **核心职责** | 资产管理、充值提现、API 绑定、账单查看 |
| **只负责** | 资金相关的一切操作 |
| **不负责** | 收益分析（去首页）、交易操作（去交易 Tab） |
| **主要模块** | 余额卡片、充值/提现入口、API Key 管理、账单明细 |

#### Tab 5：我的 (Me)

| 属性 | 内容 |
|-----|------|
| **图标** | User (用户) |
| **路由** | `/me` |
| **核心职责** | 个人信息、账户设置、会员订阅、生态中心入口、其他功能入口 |
| **只负责** | 个人账户相关、平台附加功能入口 |
| **不负责** | 具体业务操作（交易、策略、资金） |
| **主要模块** | 用户信息卡、会员状态、功能入口列表、退出登录 |

### 1.3 桌面端侧边栏（4 + 1 结构）

**设计原则**：
- 精简为 4 个核心分组 + 1 个特殊权限区
- 默认只展开「交易」组，其他组收起
- 折叠态显示图标，悬浮显示展开菜单

```
┌────────────────┬──────────────────────────────────────────────┐
│                │                                              │
│  QuantFi       │                                              │
│  ────────────  │                                              │
│                │                                              │
│  📊 仪表盘     │              [ 页面内容区 ]                   │
│                │                                              │
│  ▼ 交易        │                                              │
│    控制台      │                                              │
│    VPS 实例    │                                              │
│    交易历史    │                                              │
│    回测系统    │                                              │
│                │                                              │
│  ▶ 策略        │                                              │
│  ▶ 资产        │                                              │
│  ▶ 账户        │                                              │
│                │                                              │
│  ────────────  │                                              │
│  📢 公告       │                                              │
│  ────────────  │                                              │
│  🛡️ 管理后台   │                                              │
│                │                                              │
│  v1.15.0  🟢   │                                              │
└────────────────┴──────────────────────────────────────────────┘
```

#### 分组结构

| 分组 | 包含页面 | 默认状态 |
|-----|---------|---------|
| **仪表盘** | 仪表盘（单项，不分组） | - |
| **交易** | 交易控制台、VPS 实例、交易历史、回测系统 | **默认展开** |
| **策略** | 策略市场、我的配置、策略管理（上传+已上传+收益） | 默认收起 |
| **资产** | 钱包概览、充值、提现、API Key、账单明细 | 默认收起 |
| **账户** | 个人中心、安全中心、会员订阅、生态中心、邀请返佣、帮助 | 默认收起 |
| **底部** | 公告中心 | 固定显示 |
| **特殊权限** | 代理中心、管理后台（按角色显示） | 固定显示 |

## 三、页面去重 & 职责边界调整建议

### 3.1 问题一：`/me` 和 `/settings` 职责重叠

**现状问题**：
- `/me` 页面有「账户设置」入口
- `/settings` 页面内容与 `/me` 高度重合
- 用户困惑两个页面的区别

**整改方案**：

| 页面 | 新职责 | 包含内容 |
|-----|-------|---------|
| `/me` | 功能聚合入口 | 用户信息展示、会员状态、功能入口列表（不含具体设置项） |
| `/settings` | 账户信息设置 | 邮箱、昵称、头像、主题、语言（只负责偏好设置） |
| `/settings/security` | 安全设置 | 密码、2FA、登录日志、设备管理（独立页面） |

**具体动作**：
1. `/me` 删除重复的设置项，只保留入口
2. `/settings` 移除安全相关内容，交给 `/settings/security`
3. 移动端「我的」Tab 落地到 `/me`，不直接落地到 `/settings`

---

### 3.2 问题二：生态中心入口分散

**现状问题**：
- Sidebar 有「生态中心」独立分组（7 个子页面）
- `/me` 页面有「生态中心」入口
- 信息架构混乱，用户不知道从哪进入

**整改方案**：

| 端 | 生态中心入口位置 | 说明 |
|---|----------------|------|
| 移动端 | `/me` 页面入口（推荐） | 作为功能入口列表中的一项 |
| 桌面端 | Sidebar「账户」分组下 | 不再作为独立分组，降级为子页面 |

**具体动作**：
1. Sidebar 删除「生态中心」独立分组
2. 将「生态中心」移到「账户」分组下，作为一个入口
3. `/ecosystem` 页面作为入口页，子页面（质押、兑换等）从这里进入

---

### 3.3 问题三：策略管理页面过多

**现状问题**：
- `/strategies/my-configs` - 我的配置
- `/strategies/my-uploads` - 已上传
- `/strategies/revenue` - 策略收益
- 三个页面职责相近，用户需要多次跳转

**整改方案**：

合并为一个 Tab 切换页面 `/strategies/my`

| Tab | 内容 | 原路由 |
|----|-----|-------|
| 已订阅 | 我使用的策略配置 | `/strategies/my-configs` |
| 已上传 | 我上传的策略 | `/strategies/my-uploads` |
| 收益明细 | 策略分成收益 | `/strategies/revenue` |

**具体动作**：
1. 创建 `/strategies/my` 页面，使用 Tab 切换
2. 保留原路由作为重定向（兼容旧链接）
3. Sidebar 精简为：策略市场、我的策略、上传策略

---

### 3.4 问题四：会员订阅入口缺失

**现状问题**：
- 移动端没有「会员订阅」入口
- 只能从桌面端 Sidebar 进入
- 影响核心付费转化

**整改方案**：

| 端 | 入口位置 | 形式 |
|---|---------|-----|
| 移动端 | `/me` 页面顶部（最显眼位置） | 独立卡片，突出显示 |
| 桌面端 | Sidebar「账户」分组下 | 不再作为主导航单独项 |
| 仪表盘 | 顶部提示条（未订阅时） | 引导升级 |

**具体动作**：
1. `/me` 页面添加「会员订阅」卡片入口
2. Sidebar 删除「会员订阅」主导航项，移到「账户」分组
3. 仪表盘添加未订阅用户的升级提示

---

### 3.5 问题五：半成品页面无标记

**现状问题**：
- `/wallet/cards`、`/ecosystem/token`、`/admin/cms` 等页面功能不完整
- 用户进入后发现不可用，体验差

**整改方案**：

| 处理方式 | 适用页面 | 说明 |
|---------|---------|-----|
| 暂时隐藏入口 | `/wallet/cards`、`/trading/signals` | 从导航中移除，待功能完善后恢复 |
| 显示「开发中」标记 | `/ecosystem/token`、`/admin/cms` | 保留入口，但明确告知用户 |
| 完善功能 | `/trading/ai/analysis` | 如果短期无法完善，先隐藏 |

**具体动作**：
1. Sidebar 移除「银行卡」「交易信号」入口
2. `/ecosystem/token` 页面添加「功能开发中」提示
3. `/admin/cms`、`/admin/configs`、`/admin/audit-logs` 添加「开发中」标记

---

### 3.6 问题六：Sidebar 导航项过多

**现状问题**：
- 当前 30+ 个导航项
- 交易组和策略组都默认展开
- 信息过载，用户难以快速定位

**整改方案**：

| 分组 | 优化前 | 优化后 |
|-----|-------|-------|
| 交易 | 6 项（含 AI 策略、交易信号） | 4 项（移除半成品） |
| 策略 | 5 项 | 3 项（合并我的策略相关） |
| 资产 | 6 项（含银行卡） | 5 项（移除银行卡） |
| 生态中心 | 7 项（独立分组） | **删除分组**，移到账户下 |
| 我的 | 4 项 | **重命名为「账户」**，包含生态入口 |

**优化后导航项总数**：约 20 项（减少 30%）
