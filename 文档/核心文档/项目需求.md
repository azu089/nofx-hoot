## 🔴 v6.0 重大架构变更说明

### 变更背景

原"单租户 VPS 隔离"架构在实际测试中发现以下问题：

| 问题 | 原因 | 影响 |
|------|------|------|
| 1GB VPS 内存不足 | Freqtrade + Docker 最低需要 ~800MB | CPU 100%，服务卡死 |
| VPS 数量限制 | DO/Vultr 等云商有配额限制（10-30 台） | 无法规模化 |
| 成本过高 | 每用户 $12/月（2GB VPS） | 利润空间被压缩 |
| 运维复杂 | 管理 100+ 独立 VPS | 故障率高，排查困难 |

### 新架构：中央引擎 + 信号分发

```

### 0.5 核心代码示例

#### 0.5.1 BullMQ 信号队列

```typescript
// signal.service.ts
import { InjectQueue } from '@nestjs/bullmq';
import { Queue } from 'bullmq';

@Injectable()
export class SignalService {
  constructor(
    @InjectQueue('signal-execution')
    private signalQueue: Queue,
  ) {}

  async processSignal(signal: SignalDto) {
    const subscribers = await this.getSubscribers(signal.strategy);

    for (const user of subscribers) {
      await this.signalQueue.add('execute-order', {
        userId: user.id,
        signal,
        config: user.strategyConfig,
      }, {
        attempts: 3,
        backoff: { type: 'exponential', delay: 1000 },
      });
    }
  }
}
```

#### 0.5.2 CCXT 交易执行

```typescript
// exchange.service.ts
import * as ccxt from 'ccxt';

@Injectable()
export class ExchangeService {
  async createOrder(userId: number, params: OrderParams) {
    const credentials = await this.getDecryptedCredentials(userId);
    const exchange = new ccxt.binance({
      apiKey: credentials.apiKey,
      secret: credentials.apiSecret,
      enableRateLimit: true,
    });

    return exchange.createMarketOrder(
      params.symbol,
      params.side,
      params.amount,
    );
  }
}
```

// components/charts/KlineChart.tsx
import { createChart } from 'lightweight-charts';

export function KlineChart({ data, trades }) {
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const chart = createChart(containerRef.current!, {
      width: 800,
      height: 400,
      layout: { background: { color: '#0B0E11' } },
    });

    const series = chart.addCandlestickSeries();
    series.setData(data);

    // 添加买卖点标记
    const markers = trades.map(t => ({
      time: t.time,
      position: t.side === 'buy' ? 'belowBar' : 'aboveBar',
      color: t.side === 'buy' ? '#00C087' : '#F23645',
      shape: t.side === 'buy' ? 'arrowUp' : 'arrowDown',
    }));
    series.setMarkers(markers);

    return () => chart.remove();
  }, [data, trades]);

  return <div ref={containerRef} />;
}
```

## 第一部分：战略定位与商业全景 (Strategic Overview)

### 1.1 项目定义

QuantFi 是一个基于开源 Freqtrade 引擎深度构建的 Web3 量化 SaaS 平台。通过**中央策略引擎 + 信号分发**架构，为用户提供"选策略、绑账户、自动跟单"的一站式量化服务，并结合 GameFi 代币经济模型，将单纯的"付费工具"转化为具备"资产增值"属性的生态系统。

### 1.2 商业模式 (Business Model)

采用 **Real Yield (真实收益)** 飞轮模型：

1. **SaaS 订阅 (Cash Flow)**：用户支付月费（如 $12.9-$29.9/月），服务器成本极低（约 $0.5/用户/月），高利润率。
2. **燃油费/抽成 (Gas Fee)**：从用户盈利中抽取 15%-22%（以预充值点卡形式扣除）。这是平台核心利润来源。
3. **资产增值 (Asset Value)**：平台收入的 40% 用于回购销毁或分红，推高 $HOOT 代币价值。

### 1.3 成本模型对比 (v6.0 更新)

// order-executor.service.ts
@Injectable()
export class OrderExecutorService {

  async executeSignal(signal: Signal) {
    // 1. 获取订阅用户
    const subscribers = await this.getActiveSubscribers(signal.strategy);

    const results = { executed: 0, skipped: 0, failed: 0 };

    // 2. 并发执行（限制并发数）
    const chunks = this.chunkArray(subscribers, 10); // 每批 10 个

    for (const chunk of chunks) {
      await Promise.all(chunk.map(async (user) => {
        try {
          // 3. 风控检查
          const canTrade = await this.riskControl.check(user, signal);
          if (!canTrade.allowed) {
            results.skipped++;
            return;
          }

          // 4. 执行下单
          await this.placeOrder(user, signal);
          results.executed++;

        } catch (error) {
          results.failed++;
          this.logger.error(`User ${user.id} order failed:`, error);
        }
      }));

      // 5. 控制请求频率（避免触发交易所限制）
      await this.sleep(100);
    }

    // 6. 记录执行结果
    await this.logSignalExecution(signal, results);
  }
}

#### 2.3.3 风控检查服务

```typescript
// risk-control.service.ts
@Injectable()
export class RiskControlService {

  async check(user: User, signal: Signal): Promise<RiskCheckResult> {
    const config = await this.getUserConfig(user.id, signal.strategy);
    const positions = await this.getOpenPositions(user.id);

    // 检查 1: 最大持仓数
    if (positions.length >= config.maxPositions) {
      return { allowed: false, reason: 'max_positions_reached' };
    }

    // 检查 2: 同币种已持仓
    if (positions.some(p => p.symbol === signal.symbol)) {
      return { allowed: false, reason: 'symbol_already_open' };
    }

    // 检查 3: 账户余额
    const balance = await this.getExchangeBalance(user);
    if (balance < config.tradeAmount) {
      return { allowed: false, reason: 'insufficient_balance' };
    }

    // 检查 4: 今日交易次数（可选）
    const todayTrades = await this.getTodayTradeCount(user.id);
    if (todayTrades >= config.maxDailyTrades) {
      return { allowed: false, reason: 'daily_limit_reached' };
    }

    return { allowed: true };
  }

  // 定时任务：检查止损止盈
  @Cron('*/10 * * * * *') // 每 10 秒
  async checkStopLossTakeProfit() {
    const openPositions = await this.getAllOpenPositions();

    for (const position of openPositions) {
      const currentPrice = await this.getPrice(position.symbol);

      // 止损触发
      if (position.side === 'long' && currentPrice <= position.stopLoss) {
        await this.closePosition(position, 'stop_loss');
      }
      if (position.side === 'short' && currentPrice >= position.stopLoss) {
        await this.closePosition(position, 'stop_loss');
      }

      // 止盈触发
      if (position.side === 'long' && currentPrice >= position.takeProfit) {
        await this.closePosition(position, 'take_profit');
      }
      if (position.side === 'short' && currentPrice <= position.takeProfit) {
        await this.closePosition(position, 'take_profit');
      }
    }
  }
}

@Injectable()
export class SignalService {
  constructor(@InjectQueue('signal-execution') private signalQueue: Queue) {}

  async processSignal(signal: SignalDto) {
    const subscribers = await this.getSubscribers(signal.strategy);

    for (const user of subscribers) {

        signal,
        config: user.strategyConfig,

        backoff: { type: 'exponential', delay: 1000 },

        removeOnFail: 500,

// exchange.service.ts
import * as ccxt from 'ccxt';

@Injectable()
export class ExchangeService {
  private exchanges: Map<number, ccxt.Exchange> = new Map();

  async getExchange(userId: number): Promise<ccxt.Exchange> {
    if (this.exchanges.has(userId)) {
      return this.exchanges.get(userId);
    }

    const credentials = await this.getDecryptedCredentials(userId);
    const exchange = new ccxt.binance({
      apiKey: credentials.apiKey,
      secret: credentials.apiSecret,
      enableRateLimit: true,
    });

    this.exchanges.set(userId, exchange);
    return exchange;
  }

  async createOrder(userId: number, symbol: string, side: 'buy' | 'sell', amount: number, price?: number) {
    const exchange = await this.getExchange(userId);

    if (price) {
      return await exchange.createLimitOrder(symbol, side, amount, price);
    } else {
      return await exchange.createMarketOrder(symbol, side, amount);
    }
  }
}

#### 2.12.1 ExchangeService 完整实现

```typescript
// exchange.service.ts
import * as ccxt from 'ccxt';

@Injectable()
export class ExchangeService {

  // 获取用户的交易所实例
  async getExchange(userId: number): Promise<ccxt.Exchange> {
    const user = await this.userService.findById(userId);
    const credentials = await this.decryptCredentials(user.apiCredentials);

    // 根据用户选择的交易所创建实例
    const ExchangeClass = ccxt[user.exchangeId]; // 'binance' | 'okx' | 'bybit' ...

    const exchange = new ExchangeClass({
      apiKey: credentials.apiKey,
      secret: credentials.apiSecret,
      password: credentials.passphrase, // OKX 需要
      enableRateLimit: true,
      options: {
        defaultType: user.tradingMode, // 'spot' | 'swap' | 'future'
      },
    });

    return exchange;
  }

  // 执行开仓
  async openPosition(userId: number, signal: Signal, config: UserConfig) {
    const exchange = await this.getExchange(userId);
    const user = await this.userService.findById(userId);

    // 1. 如果是合约，先设置杠杆
    if (user.tradingMode !== 'spot') {
      await this.setLeverage(exchange, signal.symbol, config.leverage);
    }

    // 2. 计算下单数量
    const amount = await this.calculateAmount(
      exchange, signal.symbol, config.tradeAmount, signal.side
    );

    // 3. 下单
    const order = await this.createOrder(exchange, {
      symbol: signal.symbol,
      side: signal.side === 'long' ? 'buy' : 'sell',
      amount,
      type: 'market',
    });

    // 4. 获取实际成交信息
    const filledOrder = await this.waitForFill(exchange, order);

    // 5. 计算止损止盈价格
    const stopLoss = this.calcStopLoss(filledOrder.average, config.stopLoss, signal.side);
    const takeProfit = this.calcTakeProfit(filledOrder.average, config.takeProfit, signal.side);

    // 6. 如果交易所支持，设置条件单止损止盈
    if (this.supportsConditionalOrders(exchange)) {
      await this.setStopLossTakeProfit(
        exchange, signal.symbol, signal.side, stopLoss, takeProfit, filledOrder.filled
      );
    }

    return {
      orderId: filledOrder.id,
      entryPrice: filledOrder.average,
      amount: filledOrder.filled,
      stopLoss,
      takeProfit,
    };
  }

  // 设置杠杆（合约）
  private async setLeverage(exchange: ccxt.Exchange, symbol: string, leverage: number) {
    try {
      await exchange.setLeverage(leverage, symbol);
    } catch (error) {
      this.logger.warn(`Set leverage failed: ${error.message}`);
    }
  }

  // 计算下单数量
  private async calculateAmount(
    exchange: ccxt.Exchange,
    symbol: string,
    usdtAmount: number,
    side: 'long' | 'short'
  ): Promise<number> {
    const ticker = await exchange.fetchTicker(symbol);
    const price = ticker.last;
    const market = exchange.markets[symbol];

    let amount = usdtAmount / price;
    amount = exchange.amountToPrecision(symbol, amount);

    if (parseFloat(amount) < market.limits.amount.min) {
      throw new Error(`下单量小于最小限制 ${market.limits.amount.min}`);
    }

    return parseFloat(amount);
  }

  // 平仓
  async closePosition(userId: number, position: Position, reason: string) {
    const exchange = await this.getExchange(userId);
    const side = position.side === 'long' ? 'sell' : 'buy';

    const order = await exchange.createMarketOrder(
      position.symbol,
      side,
      position.amount,
      undefined,
      { reduceOnly: true }
    );

    const filledOrder = await this.waitForFill(exchange, order);
    const pnl = this.calculatePnL(position, filledOrder.average);

    return { closePrice: filledOrder.average, pnl, reason };
  }
}

#### 4.3.2 分红计算逻辑

```
每周分红计算（每周日 00:00 UTC 执行）：

1. 统计本周平台收入 (total_revenue)
2. 计算分红池 = total_revenue × 40%
3. 计算所有质押者的加权质押量：
   weighted_total = Σ (stake_amount × weight)
4. 每个用户分红：
   user_dividend = (user_stake × user_weight / weighted_total) × dividend_pool
5. 分红直接加到用户 USDT 余额
```

#### 4.3.4 质押分红服务

```typescript
// staking.service.ts
@Injectable()
export class StakingService {

  // 计算 B 类质押权重
  calculateWeight(stakedAt: Date): number {
    const days = Math.floor((Date.now() - stakedAt.getTime()) / (24 * 60 * 60 * 1000));
    return Math.min(1.0 + days / 180, 3.0);
  }

  // 每周分红（Cron: 每周日 00:00 UTC）
  @Cron('0 0 * * 0')
  async distributeDividends() {
    const weekStart = this.getWeekStart();
    const weekEnd = this.getWeekEnd();

    // 1. 统计本周平台收入
    const totalRevenue = await this.revenueRepo
      .createQueryBuilder('r')
      .select('SUM(r.amount)', 'total')
      .where('r.recorded_at BETWEEN :start AND :end', { start: weekStart, end: weekEnd })
      .getRawOne();

    const dividendPool = new Decimal(totalRevenue.total || 0).times(0.4);

    if (dividendPool.lte(0)) {
      this.logger.info('本周无收入，跳过分红');
      return;
    }

    // 2. 获取所有活跃质押
    const stakes = await this.stakingRepo.find({ where: { status: 'ACTIVE' } });

    // 3. 计算加权总量
    let weightedTotal = new Decimal(0);
    const stakeWeights = stakes.map(stake => {
      const weight = stake.stakeType === 'A' ? 1.0 : this.calculateWeight(stake.stakedAt);
      const weighted = new Decimal(stake.amount).times(weight);
      weightedTotal = weightedTotal.plus(weighted);
      return { stake, weight, weighted };
    });

    // 4. 分配分红
    for (const { stake, weight, weighted } of stakeWeights) {
      const dividend = weighted.div(weightedTotal).times(dividendPool);

      // 增加用户 USDT 余额
      await this.balanceService.addBalance(stake.userId, 'USDT', dividend.toString());

      // 记录分红
      await this.dividendRepo.save({
        userId: stake.userId,
        stakingId: stake.id,
        dividendAmount: dividend.toString(),
        weightSnapshot: weight,
        stakeSnapshot: stake.amount,
        periodStart: weekStart,
        periodEnd: weekEnd,
      });
    }

    this.logger.info(`分红完成: ${dividendPool} USDT 分配给 ${stakes.length} 位质押者`);
  }
}
```

### 4.6 邀请返佣体系 (Referral Commission System)

采用**两级返佣**机制，邀请人可获得下级活动产生的返佣收益。

#### 4.6.1 USDT 返佣（燃油费分成 - 持续收益）

当下级用户产生盈利交易并扣除燃油费时，上级从燃油费中获得 USDT 返佣：

| 层级 | 返佣比例 | 说明 |
|------|---------|------|
| 一级（直推） | 10% | 燃油费的 10% |
| 二级（间推） | 5% | 燃油费的 5% |

**计算示例**：
- 下级盈利 $100 → 燃油费 $20（20%）
- 一级返佣 = $20 × 10% = **$2 USDT**
- 二级返佣 = $20 × 5% = **$1 USDT**
- 平台实际收入 = $20 - $2 - $1 = $17

#### 4.6.2 订阅返佣（下级购买订阅 - 上级获得 USDT）

| 来源 | 触发时机 | 一级返佣 | 二级返佣 |
|------|---------|---------|---------|
| VIP 订阅 | 下级购买订阅 | 10% | 5% |

#### 4.6.3 注册奖励与空投系统（v3 配置）

**空投奖励配置**（基于行业标准研究）：

| 行为 | $HOOT 数量 | 说明 | 终身上限 |
|------|-----------|------|---------|
| 注册 | +50 | 一次性，需完成验证 | 50 |
| 绑定 TG | +10 | 一次性 | 10 |
| 绑定钱包 | +10 | 一次性 | 10 |
| 绑定邮箱 | +15 | 一次性，需邮箱验证 | 15 |
| 邀请用户 | +25 | 每成功邀请 1 人 | 2,000 (约 80 人) |
| 盈利交易 | +盈利×3 | 盈利 1 USDT = 3 HOOT | 1,000 |
| 每日签到 | +3~15 | 连续签到递增，每天+2 | 500 |

**单用户终身最大**: 3,585 HOOT（参考 Binance SIGN 4% 上限原则）

**防滥用上限配置**（双重限制）：

| 类型 | 每日上限 | 终身上限 | 说明 |
|------|---------|---------|------|
| 签到 | 15 HOOT | 500 HOOT | 连续签到最高 15/天 |
| 推荐 | 250 HOOT | 2,000 HOOT | 约 10 人/天，80 人终身 |
| 交易盈利 | 50 HOOT | 1,000 HOOT | 防止刷量 |

**Vesting 释放配置**：

| 参数 | 数值 | 说明 |
|------|------|------|
| 默认释放周期 | 90 天 | 统一线性释放 |
| 锁定期 (cliff) | 7 天 | 防止立即提现套利 |
| 最低提现 | 100 HOOT | 约 $0.10 |
| 提现手续费 | 5% 销毁 | 通缩机制 |

**防刷机制**：
- 设备指纹检测同设备多账号
- 每日上限 + 终身上限双重限制
- 7 天 cliff 锁定期防止立即提现
- 推荐和交易盈利均有终身上限保护

> ⚠️ **重要区分**：注册奖励是给**自己**，不是给邀请人。邀请人只有在下级产生消费/交易后才能获得返佣。
