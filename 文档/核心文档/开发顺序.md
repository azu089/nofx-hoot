## MVP 核心链路

```
用户付费 → 自动开 VPS → 跑策略 → 看收益 → 抽成
    ↓           ↓           ↓         ↓        ↓
  钱包系统   Cloud-Init   Freqtrade  交易同步   计费系统
```

**开发原则**：核心链路优先，UI 后补

## 风险点

| 风险 | 影响 | 缓解措施 |
|-----|------|---------|
| DigitalOcean API 不稳定 | VPS 创建失败 | 重试机制 + 告警 |
| 计费重复扣费 | 用户投诉 | unique_order_id 幂等 |
| API Key 泄露 | 资金损失 | AES-256-GCM + 内存注入 |
| 僵尸节点 | 成本浪费 | 15分钟心跳 + 自动销毁 |
| 极端行情 | 用户损失 | Kill Switch 紧急平仓 |
