## 三、财务中心（重点模块）

### 3.1 收入统计

**收入必须分三类展示**：

| 类型 | 说明 | 用途 |
|------|------|------|
| **订阅收入** | 用户订阅策略支付的费用 | 平台收入 |
| **点卡销售** | 用户购买点卡的金额 | 预付款（负债） |
| **燃油费收入** | 盈利分成扣除的点卡 | **质押分红来源** |

```
┌─────────────────────────────────────────────────────────────────┐
│  收入统计                               时间: [今日 ▼] [筛选]    │
├────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐         │
│  │  订阅收入     │  │  点卡销售     │  │  燃油费收入   │         │
│  │  $12,500     │  │  $8,200      │  │  $3,850     │ ← 分红池  │
│  │  +15.2%      │  │  +8.5%       │  │  +22.1%     │         │
│  └──────────────┘  └──────────────┘  └──────────────┘         │
│                                                                 │
│  [详细账单] [导出报表]                                          │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 点卡管理

| 字段 | 说明 |
|------|------|
| 总销售点卡 | 用户购买的点卡总额 |
| 已消费点卡 | 已用于燃油费扣除的 |
| 未消费点卡 | 用户账户剩余的（负债） |

### 3.3 燃油费明细

- 每笔盈利交易的分成记录
- 关联：用户ID、策略ID、盈利金额、分成比例、燃油费金额
- **重要**：燃油费总额 = 每周分红池

### 5.1 设计确认

```
│     HOOT      │      人        │     权重       │             │
└────────────────┴────────────────┴────────────────┴──────────────┘
```

### 5.3 权重计算规则

```
权重 = 质押数量 × 时间系数

时间系数：
- 7天:   1.0x
- 30天:  1.2x
- 90天:  1.5x
- 180天: 2.0x
- 365天: 3.0x
```

### 5.4 分红管理

**分红周期：每周**

| 字段 | 说明 |
|------|------|
| 本周燃油费收入 | 作为分红池 |
| 全网总权重 | 所有用户权重之和 |
| 单位权重分红 | 分红池 ÷ 总权重 |
| 分红时间 | 每周日 00:00 UTC |
