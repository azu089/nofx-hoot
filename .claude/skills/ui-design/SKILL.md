# UI 设计技能

你是 UI 设计专家，负责设计页面布局和交互方案。

## 设计输出格式

### 页面结构图（ASCII）
```
┌─────────────────────────────────────────┐
│  Header                                  │
├─────────────────────────────────────────┤
│  ┌─────────┐  ┌───────────────────────┐ │
│  │ Sidebar │  │  Main Content         │ │
│  │         │  │                       │ │
│  │         │  │  ┌─────┐ ┌─────┐     │ │
│  │         │  │  │Card │ │Card │     │ │
│  │         │  │  └─────┘ └─────┘     │ │
│  └─────────┘  └───────────────────────┘ │
└─────────────────────────────────────────┘
```

### 组件规格表

| 组件 | 说明 | 尺寸 | 状态 |
|------|------|------|------|
| Header | 顶部导航 | 64px 高 | - |
| Card | 数据卡片 | 自适应 | 加载/空/错误/成功 |

### 交互说明

1. **点击事件**: 描述点击后的行为
2. **加载态**: 骨架屏样式
3. **错误态**: 错误提示方式
4. **空态**: 无数据时展示

## QuantFi 设计规范

### 配色方案（华尔街风格）
- 主背景: `#0B0E11`
- 卡片背景: `#131722`
- 品牌色: `#3772FF`
- 涨/盈利: `#00C087`
- 跌/亏损: `#F23645`

### 字体层级
- 大标题: `text-xl` (20px)
- 标题: `text-lg` (18px)
- 正文: `text-sm` (14px)
- 辅助: `text-xs` (12px)

### 圆角规范
- 按钮/输入框: `rounded-sm` (6px)
- 小卡片: `rounded-md` (8px)
- 大卡片: `rounded-lg` (12px)
- 弹窗: `rounded-xl` (16px)

## 移动端适配

| 断点 | 宽度 | 导航方式 |
|------|------|----------|
| Mobile | < 768px | 底部导航 (5 Tab) |
| Tablet | 768-1024px | 底部导航 |
| Desktop | > 1024px | 左侧边栏 |
