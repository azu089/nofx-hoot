## 测试用例最小集（强制）

每个原子任务至少提供 **3 条测试用例**：

| 类型 | 说明 | 示例 |
|------|------|------|
| **正常路径** | 成功场景 | 正确邮箱密码登录成功 |
| **异常路径** | 输入非法/权限不足/依赖失败 | 错误密码登录失败 |
| **边界路径** | 空值/极值/超时/特殊字符 | 空邮箱登录返回参数错误 |

## 单元测试规范

### 文件命名

```
xxx.service.ts      -> xxx.service.spec.ts
xxx.controller.ts   -> xxx.controller.spec.ts
xxx.util.ts         -> xxx.util.spec.ts
```

### 测试结构

```typescript
describe('UserService', () => {
  let service: UserService;

  beforeEach(async () => {
    // 初始化
  });

  describe('createUser', () => {
    // 正常路径
    it('should create user with valid data', async () => {
      const result = await service.createUser(validData);
      expect(result).toBeDefined();
      expect(result.id).toBeDefined();
    });

    // 异常路径
    it('should throw error when email already exists', async () => {
      await expect(service.createUser(existingEmail))
        .rejects.toThrow('邮箱已存在');
    });

    // 边界路径
    it('should throw error when email is empty', async () => {
      await expect(service.createUser({ email: '' }))
        .rejects.toThrow('邮箱不能为空');
    });
  });
});
```

## 集成测试规范

### API 测试

```typescript
describe('AuthController (e2e)', () => {
  let app: INestApplication;

  beforeAll(async () => {
    const moduleFixture = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();

    app = moduleFixture.createNestApplication();
    await app.init();
  });

  // 正常路径
  it('POST /auth/register - success', () => {
    return request(app.getHttpServer())
      .post('/auth/register')
      .send({ email: 'test@example.com', password: 'password123' })
      .expect(201)
      .expect((res) => {
        expect(res.body.data.id).toBeDefined();
      });
  });

  // 异常路径
  it('POST /auth/register - duplicate email', () => {
    return request(app.getHttpServer())
      .post('/auth/register')
      .send({ email: 'existing@example.com', password: 'password123' })
      .expect(409);
  });

  // 边界路径
  it('POST /auth/register - invalid email', () => {
    return request(app.getHttpServer())
      .post('/auth/register')
      .send({ email: 'invalid-email', password: 'password123' })
      .expect(400);
  });
});
```

## 资金相关测试（特殊要求）

涉及资金/结算/计费/积分，必须补充 **对账/验算** 用例：

### 验算公式

```typescript
describe('WalletService - 资金验算', () => {
  it('should calculate balance correctly after deposit', async () => {
    const initialBalance = new Decimal('100.00000000');
    const depositAmount = new Decimal('50.00000000');

    const result = await service.deposit(userId, depositAmount.toString());

    // 验算：新余额 = 原余额 + 充值金额
    const expectedBalance = initialBalance.plus(depositAmount);
    expect(result.balance).toBe(expectedBalance.toString());
  });

  it('should calculate gas fee correctly', async () => {
    const profit = new Decimal('100.00000000');
    const gasFeeRate = new Decimal('0.20'); // 20%

    const result = await service.calculateGasFee(profit.toString());

    // 验算：手续费 = 盈利 * 费率
    const expectedFee = profit.times(gasFeeRate);
    expect(result.fee).toBe(expectedFee.toString());
  });
});
```

### 幂等性测试

```typescript
describe('BillingService - 幂等性', () => {
  it('should not charge twice with same order_id', async () => {
    const orderId = 'subscription_user1_1234567890_abc123';

    // 第一次扣费
    await service.charge(orderId, '25.00000000');

    // 第二次扣费（相同 order_id）
    await expect(service.charge(orderId, '25.00000000'))
      .rejects.toThrow('订单已处理');

    // 验证只扣了一次
    const logs = await billingLogRepo.find({ where: { uniqueOrderId: orderId } });
    expect(logs.length).toBe(1);
  });
});
```

## CI 集成

```yaml
# .github/workflows/test.yml
test:
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - uses: pnpm/action-setup@v2
    - run: pnpm install
    - run: pnpm test:cov
    - name: Check coverage
      run: |
        coverage=$(cat coverage/coverage-summary.json | jq '.total.lines.pct')
        if (( $(echo "$coverage < 70" | bc -l) )); then
          echo "Coverage is below 70%"
          exit 1
        fi
```
