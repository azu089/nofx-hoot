## 2.12 环境信息上报（防理想环境假设）

凡涉及运行/编译/依赖/部署/脚本，AI 计划必须包含：

| 项目 | 说明 |
|-----|------|
| OS | Windows/macOS/Linux + 版本 |
| 运行时 | Node/Python/Java 等版本 |
| 包管理器 | pnpm/npm/pip 版本 |
| Docker | 是否安装 + 版本 |
| 代理/镜像 | 是否启用 |

**环境信息缺失：禁止直接写代码，先输出环境检查清单，等 PM 回传。**

## 2.13 环境检查清单（新手友好）

遇到"命令不存在/依赖缺失/编译失败/安装失败"，AI 必须先给：

### 标准检查清单

```bash
# 1. 检查 Node.js
node -v
# 预期：v18.x 或 v20.x

# 2. 检查 pnpm
pnpm -v
# 预期：8.x 或 9.x

# 3. 检查 Docker
docker -v
docker compose version
# 预期：Docker 24.x+, Compose v2.x

# 4. 检查 PostgreSQL 客户端
psql --version
# 预期：15.x（可选，用于调试）

# 5. 检查 Redis 客户端
redis-cli --version
# 预期：7.x（可选，用于调试）
```

### 一键检查脚本

位置：`scripts/检查环境.sh`

```bash
#!/bin/bash
echo "=== QuantFi 环境检查 ==="

echo -n "Node: "
node -v 2>/dev/null || echo "未安装"

echo -n "pnpm: "
pnpm -v 2>/dev/null || echo "未安装"

echo -n "Docker: "
docker -v 2>/dev/null || echo "未安装"

echo -n "Docker Compose: "
docker compose version 2>/dev/null || echo "未安装"

echo ""
echo "=== 端口检查 ==="
lsof -i :3000 2>/dev/null | head -2 || echo "3000 端口空闲"
lsof -i :4000 2>/dev/null | head -2 || echo "4000 端口空闲"
lsof -i :5432 2>/dev/null | head -2 || echo "5432 端口空闲"
lsof -i :6379 2>/dev/null | head -2 || echo "6379 端口空闲"

echo ""
echo "=== Docker 服务 ==="
docker compose ps 2>/dev/null || echo "Docker Compose 未运行"

echo ""
echo "检查完成！"
```

## 2.14 网络/超时/镜像处理

遇到 `timeout/ETIMEDOUT/ECONNRESET/registry 不通`，必须输出：

### 超时与重试策略

```bash
# pnpm 设置超时
pnpm config set fetch-timeout 60000
pnpm config set fetch-retries 3

# npm 设置超时
npm config set fetch-timeout 60000
npm config set fetch-retries 3
```

### 镜像源方案

```bash
# pnpm 使用淘宝镜像
pnpm config set registry https://registry.npmmirror.com

# npm 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 恢复官方源
pnpm config set registry https://registry.npmjs.org
```

### 代理配置示例

```bash
# 设置代理（替换为实际代理地址）
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890

# Docker 代理配置
# 编辑 ~/.docker/config.json
{
  "proxies": {
    "default": {
      "httpProxy": "http://127.0.0.1:7890",
      "httpsProxy": "http://127.0.0.1:7890"
    }
  }
}
```

### 禁止行为

**禁止把"网络不行"当结论，必须给可执行排查路径：**

1. 检查网络连通性：`ping registry.npmjs.org`
2. 检查 DNS 解析：`nslookup registry.npmjs.org`
3. 检查代理配置：`echo $HTTP_PROXY`
4. 尝试镜像源
5. 尝试 VPN/代理
