# 中文输出规则

## 输出语言

- 所有与 PM 的交流使用**中文**
- 代码注释使用**中文**
- 变量名/函数名使用**英文**
- 文件名尽量使用**中文**（技术文件除外）

---

## 技术文件命名（必须英文）

以下文件必须使用英文命名：

- `CLAUDE.md` - Claude Code 规范
- `.claude/settings.json` - 配置文件
- `package.json` - 包配置
- `tsconfig.json` - TS 配置
- `docker-compose.yml` - Docker 配置
- `.env` 系列文件
- 代码源文件 (`.ts`, `.tsx`, `.py` 等)
- shell 脚本 (`.sh`)

---

## 中文命名（推荐）

以下文件推荐使用中文命名：

- 文档目录：`文档/`、`核心文档/`、`夜间日志/`
- Markdown 文档：`开发顺序.md`、`项目需求.md`
- Agent 定义：`后端工程师.md`、`前端工程师.md`
- Rules 规则：`开发工作流.md`、`夜间模式.md`

## 代码注释

```typescript
// 用户余额不足时返回错误
if (balance < amount) {
  throw new Error('余额不足');
}

/**
 * 计算用户的质押权重
 * @param stakeType 质押类型 A/B
 * @param lockDays 锁定天数
 * @returns 权重乘数 1.0x - 3.0x
 */
function calculateWeight(stakeType: string, lockDays: number): number {
  // A 类固定 1.0x
  if (stakeType === 'A') return 1.0;

  // B 类随时间递增，最高 3.0x
  return Math.min(1 + lockDays / 180, 3.0);
}
```

## 错误信息

用户可见的错误信息使用中文：

```typescript
// 好
throw new Error('余额不足，请先充值');
throw new Error('API Key 验证失败，请检查是否正确');

// 不好
throw new Error('Insufficient balance');
throw new Error('API Key validation failed');
```

## 日志输出

日志使用中文，便于 PM 查看：

```typescript
logger.info('用户登录成功', { userId, ip });
logger.error('VPS 心跳超时，准备销毁', { instanceId });
logger.warn('余额不足，跳过扣费', { userId, balance, amount });
```
