## Prisma 规范

### Schema 定义

```prisma
// prisma/schema.prisma
model User {
  id        String   @id @default(uuid())
  email     String   @unique
  password  String

  // 资金字段必须使用 Decimal
  usdtBalance Decimal @default(0) @db.Decimal(18, 8)
  qfiBalance  Decimal @default(0) @db.Decimal(18, 8)

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@map("users")
}
```

### Service 使用

```typescript
import { PrismaService } from '../prisma/prisma.service';
import Decimal from 'decimal.js';

@Injectable()
export class WalletService {
  constructor(private prisma: PrismaService) {}

  async deposit(userId: string, amount: string) {
    return this.prisma.$transaction(async (tx) => {
      const user = await tx.user.findUnique({ where: { id: userId } });
      const newBalance = new Decimal(user.usdtBalance.toString()).plus(amount);

      return tx.user.update({
        where: { id: userId },
        data: { usdtBalance: newBalance.toString() }
      });
    });
  }
}
```

## BullMQ 任务队列

### 定义队列

```typescript
// jobs/signal.processor.ts
import { Processor, WorkerHost } from '@nestjs/bullmq';
import { Job } from 'bullmq';

@Processor('signal')
export class SignalProcessor extends WorkerHost {
  async process(job: Job<{ strategyId: string; signal: any }>) {
    const { strategyId, signal } = job.data;

    // 分发信号给订阅用户
    await this.distributeSignal(strategyId, signal);

    return { processed: true };
  }
}
```

### 添加任务

```typescript
import { InjectQueue } from '@nestjs/bullmq';
import { Queue } from 'bullmq';

@Injectable()
export class TradingService {
  constructor(@InjectQueue('signal') private signalQueue: Queue) {}

  async broadcastSignal(strategyId: string, signal: any) {
    await this.signalQueue.add('distribute', {
      strategyId,
      signal,
    }, {
      attempts: 3,
      backoff: { type: 'exponential', delay: 1000 }
    });
  }
}
```

## CCXT 交易所集成

### 执行交易

```typescript
import * as ccxt from 'ccxt';

@Injectable()
export class ExchangeService {
  private exchanges: Map<string, ccxt.Exchange> = new Map();

  async executeOrder(
    userId: string,
    exchangeId: string,
    symbol: string,
    side: 'buy' | 'sell',
    amount: string
  ) {
    const exchange = await this.getExchange(userId, exchangeId);

    try {
      const order = await exchange.createMarketOrder(symbol, side, parseFloat(amount));
      return order;
    } catch (error) {
      if (error instanceof ccxt.InsufficientFunds) {
        throw new BadRequestException('交易所余额不足');
      }
      throw error;
    }
  }

  private async getExchange(userId: string, exchangeId: string) {
    // 获取用户加密的 API Key，解密后创建实例
    const apiKey = await this.decryptApiKey(userId, exchangeId);
    return new ccxt[exchangeId]({ apiKey: apiKey.key, secret: apiKey.secret });
  }
}
```

## Socket.io 实时通信

### WebSocket 网关

```typescript
import { WebSocketGateway, SubscribeMessage, WebSocketServer } from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';

@WebSocketGateway({ namespace: '/trading', cors: true })
export class TradingGateway {
  @WebSocketServer()
  server: Server;

  // 用户订阅策略信号
  @SubscribeMessage('subscribe')
  handleSubscribe(client: Socket, strategyId: string) {
    client.join(`strategy:${strategyId}`);
    return { subscribed: strategyId };
  }

  // 广播信号给订阅者
  broadcastSignal(strategyId: string, signal: any) {
    this.server.to(`strategy:${strategyId}`).emit('signal', signal);
  }
}
```

## 资金操作规则（最高优先级）

1. **必须使用 Decimal(18,8)**，禁止 Float
2. **计算使用 decimal.js**，禁止 JavaScript 原生运算
3. **必须使用事务**（Prisma $transaction）
4. **必须实现幂等性**（uniqueOrderId）

```typescript
// 正确示例
import Decimal from 'decimal.js';

const balance = new Decimal(user.usdtBalance.toString());
const amount = new Decimal(dto.amount);
const newBalance = balance.minus(amount);

// 错误示例（禁止）
const newBalance = user.usdtBalance - dto.amount;
```

const key = crypto.randomBytes(32);

## 前后端对齐检查（强制）

**后端功能实现后，必须检查前端 UI 是否存在对应页面/组件。**

### 检查流程

1. **后端接口完成后**，立即检查前端是否有对应 UI
2. **无 UI 时**，必须记录到 `文档/待实现UI.md`
3. **每次交付时**，汇报前后端对齐状态

### 记录格式

```markdown
## 待实现 UI 列表

| 后端接口 | 模块 | 前端页面 | 状态 | 备注 |
|---------|------|---------|------|------|
| POST /blockchain/withdraw/:id/execute | Blockchain | /admin/withdraws | ❌ 缺失 | 管理员提现执行按钮 |
| GET /blockchain/status | Blockchain | /admin/blockchain | ❌ 缺失 | 区块链监听状态页 |
| GET /wallet/deposit-address | Wallet | /wallet/deposit | ✅ 已有 | - |
```

### 交付时汇报模板

```
## 前后端对齐状态

### 本次新增后端接口
- POST /xxx - 前端 UI: ✅ 已有 / ❌ 缺失

### 缺失 UI 汇总（需后续实现）
- /admin/blockchain - 区块链监听管理页
- /admin/withdraws - 提现审核执行页
```

### 禁止行为

- ❌ 后端实现了接口但不检查前端是否有 UI
- ❌ 功能上线后用户看不到入口
- ❌ 管理后台功能无对应管理页面
