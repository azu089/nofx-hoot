## 数据库规范

### 实体定义

```typescript
@Entity('users')
export class User {
  @PrimaryGeneratedColumn('uuid')
  id: string;

  @Column({ type: 'varchar', length: 255, unique: true })
  email: string;

  // 资金字段必须使用 decimal
  @Column({ type: 'decimal', precision: 18, scale: 8, default: 0 })
  balance: string; // 注意：TypeORM 返回 string

  @CreateDateColumn({ name: 'created_at' })
  createdAt: Date;

  @UpdateDateColumn({ name: 'updated_at' })
  updatedAt: Date;
}
```

### 资金操作规则

1. **必须使用 DECIMAL(18,8)**，禁止 FLOAT/DOUBLE
2. **计算使用 decimal.js 库**，禁止 JavaScript 原生运算
3. **必须使用事务**
4. **必须实现幂等性**（unique_order_id）

```typescript
// 正确示例
import Decimal from 'decimal.js';

const balance = new Decimal(user.balance);
const amount = new Decimal(dto.amount);
const newBalance = balance.minus(amount);

// 错误示例（禁止）
const newBalance = user.balance - dto.amount;
```

## 安全规范

### 参数校验

```typescript
// 使用 class-validator
export class CreateUserDto {
  @IsEmail()
  @IsNotEmpty()
  email: string;

  @IsString()
  @MinLength(8)
  @MaxLength(32)
  password: string;
}
```

### API Key 加密

```typescript
// 加密存储
import * as crypto from 'crypto';

const key = crypto.randomBytes(32);
const iv = crypto.randomBytes(12);
const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);

let encrypted = cipher.update(apiKey, 'utf8', 'base64');
encrypted += cipher.final('base64');
const authTag = cipher.getAuthTag();

// 存储：encrypted_blob, iv, auth_tag
```

### 日志脱敏

```typescript
// 正确：只打印 ID
logger.info('用户登录', { userId: user.id, ip });

// 错误：禁止打印敏感信息
logger.info('用户登录', { email, password, apiKey });
```

## 日志规范

### 日志级别

| 级别 | 用途 |
|------|------|
| error | 需要立即处理的错误 |
| warn | 警告，可能有问题 |
| info | 关键业务操作 |
| debug | 调试信息（生产环境关闭） |

### 必须包含 request_id

```typescript
@Injectable()
export class RequestIdInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler) {
    const request = context.switchToHttp().getRequest();
    request.requestId = uuid();
    return next.handle();
  }
}
```

## QuantFi 特殊规则

### VPS 操作

1. 调用 DigitalOcean API 前必须沙盒验证
2. 创建 VPS 前检查用户余额
3. 销毁 VPS 前必须 S3 备份
4. 所有操作记录审计日志

### 计费幂等

```typescript
// 使用 unique_order_id
const orderId = `${type}_${userId}_${Date.now()}_${nonce}`;

// 数据库唯一约束
@Column({ unique: true })

```

```typescript
// 15 分钟无心跳 = 僵尸节点
const HEARTBEAT_TIMEOUT = 15 * 60 * 1000;

if (Date.now() - instance.lastHeartbeat > HEARTBEAT_TIMEOUT) {
  // 标记为僵尸节点 -> 销毁 -> 退款
}
```
