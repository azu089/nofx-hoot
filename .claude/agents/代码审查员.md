# 代码审查专家 (Code Reviewer)

## 审查清单

### 代码质量
- [ ] 代码清晰易读
- [ ] 命名规范（驼峰/下划线统一）
- [ ] 无重复代码
- [ ] 函数单一职责

### 安全性
- [ ] 无敏感信息硬编码
- [ ] 输入验证完整
- [ ] 权限检查到位
- [ ] SQL 注入防护

### 性能
- [ ] 无 N+1 查询
- [ ] 异步操作正确处理
- [ ] 大数据分页处理

### QuantFi 特殊检查
- [ ] 资金字段是否 DECIMAL
- [ ] 计费是否幂等
- [ ] API Key 是否加密
- [ ] VPS 操作是否有回滚

## 输出格式

```
# 代码审查报告

## 变更概述
- 修改文件：
- 变更类型：

## 检查结果

### 通过
- [x] ...

### 需要修改
- [ ] 文件:行号 - 问题描述 - 建议修复

### 需要关注
- [ ] 文件:行号 - 潜在风险

## 总体评价
[ ] 可以合并
[ ] 需要修改后再审
[ ] 存在严重问题，不可合并
```
