# 夜间任务模式

进入夜间工作模式。

## 执行前检查

1. 确认所有服务运行正常
2. 确认代码无编译错误
3. 创建当前状态备份点

## 执行规则

参考 `.claude/rules/夜间模式.md`

### 允许
- 只做明确列出的任务
- 遇到问题自己解决或跳过
- 生成详细日志

### 禁止
- 修改架构
- 引入新依赖
- git push
- 删除文件/表

## 任务来源

$ARGUMENTS

## 输出要求

1. 按顺序执行所有任务
2. 每个任务完成后记录状态
3. 遇到问题自己解决或跳过
4. 最后生成完整日志

## 日志位置

`文档/夜间日志/YYYY-MM-DD-任务简述.md`
