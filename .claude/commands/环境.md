# 环境检查命令

检查 QuantFi 开发环境状态。

## 检查清单

### 1. 基础环境
```bash
node -v          # 预期：v18.x 或 v20.x
pnpm -v          # 预期：8.x 或 9.x
docker -v        # 预期：24.x+
docker compose version  # 预期：v2.x
```

### 2. 端口占用
```bash
lsof -i :3000    # 前端
lsof -i :4000    # 后端 API
lsof -i :5432    # PostgreSQL
lsof -i :6379    # Redis
```

### 3. Docker 服务
```bash
docker compose ps
```

### 4. 数据库连接
```bash
psql -h localhost -U postgres -d quantfi -c "SELECT 1"
```

### 5. 代码编译
```bash
pnpm build
```
