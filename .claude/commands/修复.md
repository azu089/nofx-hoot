# 错误修复命令

诊断并修复以下错误：

$ARGUMENTS

## 修复流程

### 1. 理解问题
- 分析错误信息含义
- 确定问题根源
- 评估影响范围

### 2. 最可能原因
列出按概率排序的 3 个最可能原因：
1. [原因1] - 概率最高
2. [原因2]
3. [原因3]

### 3. 检查步骤
每个原因的检查命令和预期输出

### 4. 最小修复
- 改动越少，风险越小
- 不顺手重构
- 不顺手加功能

### 5. 验证修复
- 原问题解决
- 相关功能没坏
- 编译无报错

## 输出格式

```markdown
## 错误诊断报告

### 错误含义（大白话）
[1-2 句解释]

### 最可能原因
1. [原因1]
2. [原因2]
3. [原因3]

### 检查结果
- 检查1：[结果]
- 检查2：[结果]

### 修复方案
- 修改：[文件和内容]
- 复测：[命令]
- 预期：[结果]

### 回滚方案
[如何撤销]
```
