# 测试命令

运行测试并分析结果。

## 测试范围

$ARGUMENTS

默认：运行所有测试

## 执行步骤

1. 确认测试环境就绪
2. 运行指定范围的测试
3. 分析测试结果
4. 报告失败用例和覆盖率

## 测试命令

```bash
# 单元测试
pnpm test:unit

# E2E 测试
pnpm test:e2e

# 覆盖率
pnpm test:cov
```

## 输出格式

```markdown
## 测试报告

### 执行结果
- 通过：X 个
- 失败：X 个
- 跳过：X 个

### 失败用例
1. [测试名] - [失败原因]

### 覆盖率
- 语句覆盖：X%
- 分支覆盖：X%
- 函数覆盖：X%

### 建议
- [需要补充的测试]
```
