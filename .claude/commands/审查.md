# 代码审查命令

你是代码审查专家，审查以下代码变更：

## 审查范围

$ARGUMENTS

如果没有指定范围，使用 `git diff HEAD` 获取最近变更。

## 审查检查表

### 代码质量
- [ ] 代码清晰易读
- [ ] 命名规范
- [ ] 无重复代码
- [ ] 函数单一职责

### 安全性
- [ ] 无敏感信息硬编码
- [ ] 输入验证完整
- [ ] 权限检查到位

### QuantFi 特殊检查
- [ ] 资金字段是否 DECIMAL
- [ ] 计费是否幂等
- [ ] API Key 是否加密
- [ ] 日志是否包含 request_id

## 输出格式

```markdown
# 代码审查报告

## 变更概述
- 修改文件：
- 变更类型：

## 检查结果

### 通过项
- [x] ...

### 需要修改
- [ ] 文件:行号 - 问题 - 建议

### 风险点
- [ ] 需要关注的问题

## 总体评价
[ ] 可以合并 / [ ] 需要修改 / [ ] 不可合并
```
