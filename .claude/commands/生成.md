# 代码生成命令

生成代码模板：$ARGUMENTS

## 支持的类型

### 后端（NestJS）
| 类型 | 示例 | 生成文件 |
|------|------|----------|
| entity | `/生成 entity User` | user.entity.ts |
| dto | `/生成 dto CreateUser` | create-user.dto.ts |
| service | `/生成 service User` | user.service.ts |
| controller | `/生成 controller User` | user.controller.ts |
| module | `/生成 module User` | user.module.ts |

### 前端（Next.js）
| 类型 | 示例 | 生成文件 |
|------|------|----------|
| page | `/生成 page Dashboard` | dashboard/page.tsx |
| component | `/生成 component UserCard` | UserCard.tsx |
| hook | `/生成 hook useAuth` | useAuth.ts |
| store | `/生成 store user` | userStore.ts |

## 生成规则

1. **命名规范**
   - Entity: PascalCase，单数（User, Wallet）
   - 文件名: kebab-case（user.service.ts）

2. **必须包含**
   - TypeScript 类型定义
   - 必要的导入语句
   - 基础错误处理

3. **禁止生成**
   - 硬编码的配置值
   - 明文密码/密钥
   - any 类型

## 生成后提示

1. 生成代码后需要手动完善 TODO 标记
2. 涉及资金的代码必须使用 Decimal
3. 新文件需要在对应 module 中注册
