# 项目状态命令

查看 QuantFi 项目当前开发状态。

## 检查项目

1. 读取 `文档/核心文档/开发顺序.md` 确定当前阶段
2. 检查最近的变更（git log）
3. 检查服务运行状态
4. 输出状态摘要

## 输出格式

```markdown
## 当前开发状态

### 所处阶段
Phase X: [阶段名称]

### 服务状态
- API: [运行中/停止]
- Web: [运行中/停止]
- DB: [运行中/停止]

### 已完成
- [x] 任务1
- [x] 任务2

### 进行中
- [ ] 任务3 - [进度说明]

### 待开始
- [ ] 任务4

### 最近变更
- [时间] [描述]

### 下一步建议
1. [建议1]
2. [建议2]
```
