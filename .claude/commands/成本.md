# 成本统计命令

查看当前会话的资源使用情况。

## 统计项目

1. **Token 使用**
   - 输入 Token 数
   - 输出 Token 数
   - 缓存命中率

2. **成本估算**
   - 当前会话成本
   - 累计成本

3. **代码变更统计**
   - 新增行数
   - 删除行数
   - 修改文件数

## 使用内置命令

请使用 `/cost` 查看详细成本信息。

## 优化建议

- 使用 `/compact` 压缩上下文减少 Token 使用
- 复杂任务使用 haiku 模型降低成本
- 避免重复读取大文件
