# 原子任务指令模板

> PM 下达任务时复制此模板填写

---

## 模板格式

```
【阶段标记】
Phase X - Task X.X: [任务名称]

【本轮只做什么】
- [具体任务1]
- [具体任务2]
- 必须可验收

【本轮不做什么】
- 不动 [模块/文件/接口1]
- 不动 [模块/文件/接口2]
- 不做 [功能/优化/重构]

【验收方式】
1. [步骤1] - 预期看到：[结果]
2. [步骤2] - 预期看到：[结果]
3. [步骤3] - 预期看到：[结果]

【回滚要求】
- 必须可回退到上一个稳定版本
- 回滚命令：[具体命令]

【环境信息】（如涉及运行）
- OS: [macOS/Windows/Linux + 版本]
- Node: [版本]
- pnpm: [版本]
- Docker: [是/否 + 版本]
- 代理/镜像: [是/否]
```

---

## 示例：数据库 Schema 设计

```
【阶段标记】
Phase 1 - Task 1.1: PostgreSQL 全局 Schema 设计

【本轮只做什么】
- 设计 5 大模块的数据库表结构
- 输出 SQL 文件和 Mermaid ER 图
- 添加详细注释说明字段用途

【本轮不做什么】
- 不执行 SQL（只设计）
- 不创建 Docker 配置
- 不写后端代码

【验收方式】
1. 查看 database/schema.sql - 预期看到：完整的建表语句
2. 查看 database/er-diagram.md - 预期看到：Mermaid ER 图代码
3. 所有资金字段使用 DECIMAL 类型

【回滚要求】
- 删除 database/ 目录即可回滚

【环境信息】
- 本任务不涉及运行
```

## 示例：API 接口开发

```
【阶段标记】
Phase 2 - Task 2.1: 用户注册接口

【本轮只做什么】
- 创建 POST /api/auth/register 接口
- 实现邮箱+密码注册
- 密码 bcrypt 加密存储

【本轮不做什么】
- 不做登录接口
- 不做邮箱验证
- 不改前端

【验收方式】
1. curl 调用注册接口 - 预期看到：返回 201 + user_id
2. 查询数据库 - 预期看到：用户记录已创建
3. 重复注册 - 预期看到：返回 409 邮箱已存在

【回滚要求】
- git revert 最近一次提交
- 回滚命令：git revert HEAD

【环境信息】
- OS: macOS 14.0
- Node: v20.10.0
- pnpm: 9.0.0
- Docker: 是 v24.0.7
```

## 示例：前端页面开发

```
【阶段标记】
Phase 2 - Task 2.5: 登录页面

【本轮只做什么】
- 创建登录页面 /login
- 实现邮箱+密码表单
- 调用后端登录接口

【本轮不做什么】
- 不做注册页面
- 不做找回密码
- 不改后端接口

【验收方式】
1. 打开 http://localhost:3000/login - 预期看到：登录表单
2. 输入正确账号登录 - 预期看到：跳转到 Dashboard
3. 输入错误密码 - 预期看到：显示错误提示

【回滚要求】
- git revert 最近一次提交

【环境信息】
- OS: macOS 14.0
- Node: v20.10.0
- pnpm: 9.0.0
```
